## 实施顺序与完成条件

1. **SSW闭环**：把Safe-total作为独立driver的可选数值后端，复用其算法，保持原有E/F、
   失败和真淬火接口；用现有Cu13比较完整轨迹。通过条件是有效逃逸、独立真力检查和完整成本，
   不要求复制native浮点轨迹。团簇方向采用已核验的刚体方向投影作为工作基线，固定截面保留对照。
2. **LS闭环**：补齐原版初始化表到实际振幅及更新的必要映射，保留明确的论文参数模式。
   在有来源输入/参数的分子体系完成SSW与LS-SSW端到端比较；先检查化学结构变化再讨论效率。
3. **GA闭环**：补TYPE0 mutation和controller，形成ASE原子/合金GA-SSW完整示例；复用已通过
   原JAR对照的crossover和既有archive/population组件。TYPE3已存在的路径继续保留。
4. **交付固定胞版本**：统一公开API、可运行示例、参数来源和验证报告，再规划周期/联合变胞/RC。

并行工作限于当前实施步骤的独立子任务。只有阻止实现或改变科学结论的问题才开展进一步反编译。
不以同一失败样本上的局部修复宣布全局搜索胜出；不在完整验证前更换稳定PAM生产分支。

## 总体目标与滚动推进（用户 2026-09-10 补充）

最终目标包括 SSW、LS-SSW、GA-SSW、VC-SSW 等独立 ASE 实现，并吸收 LASP 中有证据支持的设计；
固定胞交付是里程碑，不是最终范围的终点。主智能体负责问题定义、任务分解、集成审查和真实体系验证，
子智能体承担有明确文件边界的实现或反编译任务。只有会改变主线的重要结论或阻塞需要汇报后暂停。

当前先完成原版 LBFGS/MCSRCH/MCSTEP 机器码与 Safe-total 的冻结目标比较。必须分开记录
机器码 kernel、完整 BFGSDRIVER 调用语义、独立 Python 搜索三层，不能以 ASE 同名算法代替原版。
随后执行同输入/种子的完整 Cu13 SSW，记录全部成本、失败、真实力复核与结构变化。

固定胞闭环后的 VC 阶段必须明确联合原子/应变坐标、物理度量、E+pV 与应力链式法则，
让晶胞自由度实际参与方向选择、偏置及逃逸；仅末端 cell-relax 不满足 VC-SSW 验收。
RC/其他变体由真实体系暴露的需求排序，不预先堆叠所有算子。
每个 LASP 设计的处理须区分“已恢复行为”“论文解释”“待验证的可用改进”；
反编译与文献检索仅用于当前实现或科学判断的具体缺口。
