# AlOH 固定胞优化器对照：分析约定

本轮只比较现有 Safe-total、ASE LBFGSLineSearch、SciPy L-BFGS-B 在同一个
SSW 流程中的表现。上传 TYPE1-AlOH 的前两个晶体帧各自作为配对初态，seed11。
固定各自晶胞，MACE-OMAT-0-small/CPU/float64；这不是原文 LASP 势的数值复现，
也不是变胞相稳定性测试。后端 E/F/stress 接口此前已经核验，不重复消耗调用。

执行参数与预算以运行前冻结的 plan.json 为准；优化器之外的方向、Gaussian、
内外阈值保持相同。不混入未核实的 Al LS 键表，不按结果调 history 或线搜索。

先检查六个配置实际使用了三个不同优化器，再报告所有失败与截断。
总成本包括初始淬火、方向/偏置求值、失败试探及独立核验。独立核验要求
重新清除计算器缓存、能量差绝对值 <=1e-7 eV、原子力范数最大值 <=.03 eV/Å，
保持组分/晶胞/PBC。固定胞应力只作诊断，不要求为零。

每个初态分别比较合格落点的能量下降与累计调用，必要时截到该初态三组共同
请求前缀。若只完成初始淬火或没有新合格落点，不以偏置面低能或末次试探值
代替搜索进展。两个初态和一个 seed 不足以判断通用优化器优劣。

离线结构分析采用包含周期镜像的邻居表，记录最短距离、Al–O 配位数
（2.1/2.3/2.5 Å 敏感性带）、H 最近 O 与距离、H–O 配位数
（1.1/1.2/1.3/1.5 Å）。这些是诊断范围，不是新搜索参数或严格化学键定义。
原子标号的 H–O 归属变化只提示候选局部重排，不证明新晶相/独立盆地。
小梯度和合理几何均不能替代 Hessian 或 DFT 稳定性验证。

若共同瓶颈在方向旋转或 Gaussian 构造，本轮不得据此添加优化器回退；
只有真实平滑目标上重复出现明确优化器失效时，再设计单因素修复。
