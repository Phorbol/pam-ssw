# Native-LS 固定胞周期镜像：实现与有界真实体系验证

## 决定

保留显式 `NativeLSSettings(bond_geometry='periodic-images')`，默认仍为
`native-mic`。同一周期键集合同时进入势能/力和初始化、响应更新的 Nb。
完整镜像求和修复短胞表示相关的力相消问题，尚未证明搜索效率优势。
原理和原版 MIC 证据见 `2026-09-12-native-ls-domain-audit.md`。

## 冻结协议

产物：`research/ga_ssw/evidence/native-ls-periodic-multicase-20260912/`。
完整 pamssw 源码在运行前复制到 source，子进程实际导入路径记录在
runtime-import.json；runner.py、config.json、plan.json、input.extxyz、
每条 E/F 请求账本及 raw_result 均保留。

Cu/Al conventional fcc 分别 a=3.6/4.05 Å；4 原子完整晶体和 pristine
2×2×2 conventional 超胞删一个原子得到的31原子空位结构。每个输入只对
当前 atom0 施加 [0.12,-0.08,0.06] Å 位移。ASE EMT，seed11，每臂两次
SSW尝试，4000请求/60秒上限，无补跑或调参。Safe-total，bias_fmax=.1、
真实势 fmax=.01 eV/Å，relax_steps=200，其余完整参数在 config.json。

D=1 eV、Cu/Al length=2.9/3.0 Å 是事先声明的诊断表，不是 LASP 金属查表
或经标定的通用参数。本实验检验几何扩展的可运行性及共同失败机制。

## 实际结果

| 输入 | MIC 状态/搜索请求 | 镜像状态/搜索请求 | 独立复核数 MIC/镜像 |
|---|---|---|---|
| Cu4 | LS预淬火失败 / 186 | 完成两步 / 426 | 1 / 3 |
| Cu31 | 完成两步 / 461 | 完成两步 / 461 | 3 / 3 |
| Al4 | LS预淬火失败 / 225 | 完成两步 / 355 | 1 / 3 |
| Al31 | 完成两步 / 380 | 完成两步 / 386 | 3 / 3 |

根智能体独立逐行核对 charged 账本与公共结果请求数，合计2880搜索请求。
20个保存结构各用新 EMT 实例复核一次，总成本2900次 E/F 请求；全部能量差
≤1e-8 eV、最大原子力≤.01 eV/Å，晶胞逐元素精确不变。距离仅记录为
诊断，没有事后增加距离资格阈值。无请求拒绝或预算封顶。

两个 MIC 失败都发生在软面预淬火，未进入后续爬坡；它们只保存了初始真实
极小值，不能计为成功搜索。其余六臂各有两条 gaussian_limit 记录并接受
真实淬火结果。接受或保存次数不等于不同盆地数，未做新盆地/GM命中声明。

## 结论边界与下一步

Cu和Al短胞重复出现同一失败，且有完整镜像的力对称性诊断支持，因此
保留显式扩展。超胞两种模式都可运行，不支持把所有旧MIC轨迹都视为错误。
没有改变原版模式或通用阈值，没有证明原版 LASP 主程序在这些输入上必然
失败，也没有将短轨迹称作生产级全局优化效率验证。

继续处理固定胞SSW阶段控制和native-LS约束接口；不围绕这四个开发输入
继续调强度、宽度、步数或停止阈值。
