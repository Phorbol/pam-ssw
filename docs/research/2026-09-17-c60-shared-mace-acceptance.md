发现验收口径的实质差异：LASP 日志 force=0.047021986 eV/Å 等于最大笛卡尔分量，末帧最大原子力向量范数则为 0.066193890 eV/Å。因此原生 ftol=.05 不等同于 ASE 最大原子力范数 fmax=.05。正式比较使用公共、独立的最大原子力范数检查，原生原始停点与后续公共复核/淬火成本分别保留；不得把日志合格直接计为共同数值资格合格。三维范数与最大分量满足 max_component <= max_atom_norm <= sqrt(3)*max_component，属于不同定义，不是 MACE 接口误差。

### 结构验收依据

富勒烯图应为三配位、三连通平面图，仅含五元和六元面；60 顶点时由 Euler 关系得到 12 个五元面和 20 个六元面。原始数学文献：[Extremal fullerene graphs with the maximum Clar number](https://arxiv.org/abs/0801.1788)。这为拓扑必要检查提供依据，但距离构图本身仍需物理键长判据与敏感性核验，抽象平面图也不能单独证明三维坐标是合理的空心笼。与已知 Ih 图同构应另外记录，不要求所有完整笼都必须为 Ih。

1. 在同一后端优化并核验参考笼，确定能量参考及数值误差。
2. 已完成真实 LASP 完整偏置逃逸接口检查；正式对照前统一独立资格检查口径。
3. 冻结随机初态分布、公共输入、独立种子、笼结构判据、能量容差与等成本预算，再开展 LASP/独立 Python SSW 对照；LS 作为明确的独立比较臂。

此决定消除了必须用不同势函数比较 LASP 与 Python 的限制。当前不需要为该对照获取 LASP 碳 NN 势；尚无算法胜负或 C60 成功率结论。
