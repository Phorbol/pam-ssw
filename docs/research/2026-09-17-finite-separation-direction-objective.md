# 有限间距方向问题：残差究竟在收敛什么

这是针对当前固定胞、无约束或固定正交投影、相同旋转面与固定 anchor 的数学推导，不是新机制，也不声称来自原版源码。

设中心 R、间距 d>0、单位方向 n、单位参考方向 u、旋转偏置强度 a。令

```
g_d(n) = [∇V(R+d n)-∇V(R)]/d - a (u·n)u
r_d(n) = (I-n nᵀ)g_d(n)
```

公共求解器当前返回的直接残差就是 `||r_d||`，单位 eV/Å²。
有限 d 下它不是严格的固定 Hessian 本征残差，但仍有明确的势能目标：

```
Φ_d(n) = [V(R+d n)-V(R)-d ∇V(R)·n]/d² - (a/2)(u·n)²
∇_n Φ_d = g_d(n)
grad_sphere Φ_d = r_d(n),  ||n||=1.
```

因此有限差分的非线性**并不意味着驻定方向不存在或必然无法收敛**。它意味着当前三种求解器使用的近似不同：Broyden直接求球面驻定残差的根；Ritz把不同方向的 `g_d(n)` 当作近似线性算子的列来构建对称投影；平面dimer也用局部二阶/二维旋转近似。小残差本身不保证球面极小值，更不保证最低曲率本征向量。

对足够光滑 V，Taylor 展开给出

```
Φ_d(n) = 1/2 nᵀ(H-a uuᵀ)n + d/6 ∇³V[n,n,n] + O(d²)
g_d(n) = (H-a uuᵀ)n + d/2 ∇³V[n,n] + O(d²).
```

Ritz 的最终直接求值认证很必要：子空间线性组合的残差小，并不保证同一返回方向的真实 `r_d` 小。相反，三个求解器都达到预算仍不收敛，也不能单凭此事实认定有限差分误差是根因；预算、谱间隙、数值噪声和迭代路径均可能参与。

若要区分，应先保存同一中心/anchor上的返回方向和直接认证，只有出现相关异常时，再对同一方向比较不同 d 或中心差分；不能用更宽松的门槛掩盖公式错误。对称差分抵消上述一阶项，但需要更多力调用，是后续有证据时才考虑的对照。

原版恢复的旋转报告力与这里的残差有 `F_report=10 d ||r_d||` 关系（见CBD阶段审计）。精度换算只改变停止门槛，不改变 Φ_d；不能据此推导方向误差或搜索质量改善100倍。
