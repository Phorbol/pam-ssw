# 方向精度、停止语义与完整SSW：阶段结论

## 要解决的问题

原版旋转报告力和公共HVP残差的尺度不同。不能用同名同数值tol比较求解器，更不能从旋转收敛推出搜索有效。本轮保持共享驱动、偏置/淬火设置一致，比较Ritz、现有平面dimer、恢复算术的Euclidean Broyden。不是原版LASP全流程对比，也不是ASE标准dimer软件的性能排名。

协议：[预注册条件](2026-09-17-matched-direction-protocol.md)。后端MACE-OMAT-0-small/CUDA/float64，AlOH26与brookite48各两个seed，每臂6000搜索E/F请求，旋转直接残差0.02 eV/Å²、间距0.001 Å，内层/外层力阈值0.1/0.03 eV/Å。仅数值主旋转求解器不同。所有源码/输入/模型标识已冻结。

## 完整搜索结果

下表结构数**包含初始结构**，用周期StructureMatcher的较严格设置(ltol=.1,stol=.15,angle_tol=2°)，不缩放晶胞。它是近似结构分类，不是正定Hessian或相身份认证。能量差相对各臂初始淬火；两个seed分别列出。

|体系|方向求解器|结构数(seed11/29)|最低ΔE/eV(seed11/29)|旋转失败数(seed11/29)|
|---|---|---|---|---|
|AlOH26|Ritz|2 / 7|−0.000530 / −0.588863|5 / 1|
|AlOH26|平面dimer|1 / 1|0 / 0|21 / 18|
|AlOH26|Euclidean Broyden|5 / 7|−0.739982 / −0.589887|0 / 0|
|brookite48|Ritz|2 / 2|−0.000745 / −0.000893|0 / 0|
|brookite48|平面dimer|1 / 1|−0.000963 / 0|0 / 2|
|brookite48|Euclidean Broyden|1 / 2|−0.000952 / −0.001050|0 / 0|

较宽松结构容差(.2,.3,5°)下，AlOH的Ritz结构数变为1/5、Broyden为5/6，dimer仍1/1；brookite各项不变。Ritz在brookite发现的另外结构比初始高约1.69和1.97 eV，Broyden仅seed29发现约+1.97 eV结构。因此Broyden改善AlOH上的有效落点与降能，却没有在两体系所有目标上支配Ritz。

全体落点的AlOH最短周期距离0.971–1.013 Å，H最近O距离0.971–1.082 Å，Al–O配位(2.3 Å截断)为4–6；brookite最短周期距离1.759–1.871 Å，Ti–O配位为5–6。未见原子碰撞或明显O–H解离。配位改变不自动代表错误或真实新相；这是模型上的局部几何筛查，尚未做DFT或正定Hessian验证。

## 最重要的新发现：残差排名会随被求解的数学对象改变

冻结AlOH初始结构，Ritz/Broyden在约19–22次主旋转请求达到0.02；平面dimer用完94请求仍有0.091/0.155残差。但它与Ritz方向只差2.13°/1.95°，有偏曲率只差约0.003 eV/Å²。严格残差失败不能直接等同于“方向不能用于逃逸”。

更关键的是在两处**完全相同的Ritz失败现场**，保持中心、anchor、a和预算不变：

|现场|求解器|主旋转请求|原单边残差|同返回方向中心差分残差|
|---|---|---:|---:|---:|
|AlOH seed11|Ritz|94|0.020456|0.011395|
|AlOH seed11|Broyden|20|0.016713|0.029059|
|AlOH seed29|Ritz|94|0.020101|0.013931|
|AlOH seed29|Broyden|19|0.019929|0.025875|

中心差分只是进一步数值诊断，不是精确Hessian真值；但这一变化足以证明：**Broyden更快收敛当前有限间距驻定方程，不等价于更准确地求出中心Hessian模式。** Ritz的失败也不能一概归为方向质量差。半间距单边证书与中心差分趋势相符。平面dimer在失败现场中心差分仍有0.052/0.100残差，不能把其失效完全归因于同一种单边截断效应。

原因是有限间距下，直接残差对应球面势能目标Φ_d的梯度，而Ritz使用近似线性/对称算子；[推导](2026-09-17-finite-separation-direction-objective.md)给出明确公式。对称差分会改变被认证的对象，不能静默替换原证书。

门槛2的冻结实验能在4–12次主旋转请求停止，但残差约1.2–2、曲率和方向也不同；这不是证明全局搜索可无损放宽100倍。该数值仅来自前次显式native-ftol诊断的换算，不是宣称LASP默认参数。

## 决定与需要讨论的设计

1. 保留Euclidean Broyden作为有真实材料支持的候选；不宣布其普遍优于Ritz、不改默认，也不把它称为完整CBD/BP-CBD。
2. 当前最重要的核心契约是：方向旋转究竟必须严格收敛才能生成proposal，还是允许在有限预算下返回近似软化方向？已恢复的原版停止逻辑区分force-stop与rotmax-stop；当前公共驱动把未达残差门槛一律丢弃，这会浪费之前的Gaussian爬坡。
3. 建议下一项仅比较“严格残差放行”与“有限旋转预算结束后进入后续逃逸”，显式保留收敛/预算结束/真正失败三种状态，真实落点力门槛保持不变。它改变方向模块与外层驱动的验收契约，应先讨论清楚，再以同预算多体系端到端证据判断，不能直接把tol改成2。
4. 在这个核心契约清楚以前不扩展GA路由或新的启发式。LS/GA/VC/RC已有功能状态不因本次测试升级。
