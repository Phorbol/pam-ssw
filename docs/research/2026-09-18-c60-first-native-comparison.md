# 随机 C60 首轮同模型对照：能力缺口与下一优先级

## 决策摘要

真实 LASP 已通过外部接口使用 MACE-OMAT-0-small 完成完整 SSW 搜索。两个随机碳云上，原版获得的最低力合格落点比本次两类 Python 配置低。没有任何配置达到 C60 笼或参考能量目标。这是开发诊断，不是正式独立成功率或普遍性能排名。

原受限恢复方向两次均因 c1 的 12 Å 全近域检查停止。显式逐原子屏蔽修正解除这一阻塞，但没有追平原版。优先研究完整逃逸效率，不能继续把优化器历史长度、增加迭代数或组件移植数量当作主要进展。GA/VC 暂不抢占主线。

## 协议与实际结果

输入为球内随机60C，半径5 Å、最小间距1 Å、seed17093/17094；这些是暂定开发分布，不是论文最优值。各方法使用同一生成碳云；ARC/EXTXYZ序列化使输入坐标最大差约5e-9 Å，不能宣称位级相同初态或逐轨迹配对。后续固定公共序列化精度。原生使用日志记录的时间种子，Python使用显式种子，不能声称相同随机流。

能量后端相同。参考笼 E=-514.5727735075726 eV，最大原子力范数0.00038866 eV/Å；其图结构和三维凸包已独立核验。参考能量并未被证明为此模型的全局最低值。

本批公共力资格为最大原子力范数<=.03 eV/Å；原生ftol=.03/sqrt(3)采用更严格的充分条件。原生保留SI重连/压缩设置，关闭内部LJ；Python本批没有LS、重连、PAM自适应Gaussian或native高度策略。两种Python方向配置共享Safe-total/history500等设置，仅方向规则不同。不能据此评价所有PAM配置，更不能把差距归因于单一机制。

这八条开发运行合计39618次搜索E/F请求和44次Python独立资格复核。原生38个Minimum found事件全部通过累计调用编号、打印能量与力分量匹配，资格检查使用其真实MACE力向量；没有把局部优化中间帧当作极小值。表中落点不代表去重后的盆地数。

每种配置两条已尝试轨迹中，完整笼与`E<=Eref+.01 eV`两个目标均为0/2；受限失败和行政截断保留在分母/状态中。这不是成功概率估计，也不是论文预算下的否定结果。0.01 eV是本开发分析的操作容差，参考收紧力阈值后的能量变化约0.000103 eV。所有候选均未通过笼图必要条件，因而没有需要升级为“物理合格完整笼”的正候选。

## c1 修正的数学含义与边界

令M表示距所选原子12 Å内的坐标选择，P去除整个自由团簇的平移和转动。新选项使用P(Mr)，而不是M(Pr)。投影可能在邻域外产生补偿位移；它不是把邻域外原子固定住。12 Å沿用原版经验尺度，不宣称由第一性原理导出。

`RecoveredDirectionSettings.c1_radius_policy`默认仍为`restricted`，显式`per_atom`才启用修正。保留原有随机数、CBD、方向混合及默认行为，不复制上传ELF中错误清除最后原子mask的索引行为。此选项是独立科学修正变体，不是二进制逐步等价复现。

Root复核仅有两个核心模块相对冻结父版本变化；针对性pytest为19 passed，`git diff --check`通过。真实回归两条都越过原停止位置并达到6000请求上限。支持“解除适用域阻塞”，不支持“提高每次请求的搜索收益”；两节点浮点路径也不能默认为逐步相同。

## 下一项科学问题与不应采取的动作

### 用户质疑后的归因修正：先核对参数和预算分配

本轮不能区分参数、数值预算分配与算法机制的贡献。不能因原版落点更低就直接将下一优先级归结为新算法设计。生效配置核验：双方NG12、ds/width=.6、T150、真实优化上限1000；原生DimerdR=.005 Å而Python fd_step=.001 Å；原生预旋转/旋转上限5/15，而恢复方向为2/8。旋转阈值的定义与归一化也未统一，不能直接按输入数值比较精度。

Python `bias_stage_steps=None`使每个偏置淬火继承1000步上限、bias_fmax=.1；原版生效Ngaus_relax/ini/half为15/5/10，使用其分阶段停止逻辑。这些设置不是同一语义的局部预算，不能只因两边MaxOptstep均1000就称数值协议相同，也不能据此说Python实际每阶段都花了1000步。

从两个Python通用方向原始result.json的climb事件复核：已记录58/46个旋转，每个均为40次力请求，总2320/1840；已记录偏置淬火请求合计2651/2966，中位数42/53.5，最大130/243。这是已记录事件的部分成本分解，不包含所有初始化、落点淬火、未完成末阶段及其他调用，不能强行与总6000相加配平。

除初态外，原版获得16/20个公共力合格落点，Python通用方向8/5个，修正恢复方向11/8个；这些未做结构去重。差异说明有效外步机会不同，但尚不能判定来自旋转精度、偏置淬火要求、提议质量或其他流程。下一步先在相同已保存状态下对照生效参数、旋转停止量和短偏置优化；保持真实落点力资格，不通过放宽最终验收制造成功。并报告最佳合格能量随累计E/F请求的曲线和每外步成本，在参数定义/预算分配澄清后再隔离偏置策略与碎片处理。6000请求仅为开发预算，不能替代长预算C60验收。

当前Python默认Gaussian高度由前向力平衡计算，并非统一固定高度；它与原版高度控制、已有PAM曲率自适应策略应分别命名，不应把本批概括成固定高度对自适应高度的实验。

竞争解释至少包括：（1）偏置高度、方向软化和偏置退出规则不同；（2）原版碎片重连/压缩路径不同。现有全流程对照不能区分二者。下一轮应先对同一已保存起点/方向核查实际偏置高度和退出事件，再以现有PAM自适应Gaussian作单独对照；随后隔离重连作用。保留至少一个非C60真实体系复核，避免按这两个开发种子调参。

不增加未经推导的回退或奖励项，不把修正变体改为通用默认，不因2种子结果宣称LASP普遍更好，也不继续以6000请求开发预算替代长预算C60验收。正式搜索需新种子、更充分的预先固定预算，并给外部接口足够墙钟时间。
