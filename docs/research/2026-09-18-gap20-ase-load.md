## 正确加载

在模型目录运行：

```python
from quippy.potential import Potential
atoms.calc = Potential(args_str='', param_filename='Carbon_GAP_20.xml')
energy = atoms.get_potential_energy()
forces = atoms.get_forces()
```

空 args_str 使 QUIP 使用 XML 顶层定义的 Sum(IP Glue, IP GAP)。官方示例同样保留空初始化字符串。
不要替换成仅 IP GAP 而丢掉解析项；不要删除同目录的 sparseX 文件。
主 XML 已包含 Glue 参数，无需再次添加外部 r6_innercut.xml 造成重复计数。
