# 固定胞 SSW 的显式原版 MC 接入与重复基线

目标：把已经核验的独立原版 MC 函数接入 ASE 搜索主驱动，并使后续比较具备可检查的重复基线。
不改 SSW 的旋转、Gaussian、内层优化器或默认接受策略。

## 最小接口约定

`run_ssw(..., mc=None)` 保持普通 Metropolis 原路径；显式传入 `NativeMCSettings(energy_tol, maxtrap)`
才使用已恢复的 native_metropolis。两个参数均须明确提供，不给来源不明的新默认。
每个 walker 独立持有 NativeMCState；每次合格且通过已有选择检查的真实落点消费一次均匀随机数，
包括下坡/等能，随后记录概率、计数、有效温度与接受结果。失败淬火不触发 MC。
所有合格真实落点仍保留在 minima，拒绝只影响下一个搜索起点。

只为启用 native MC 的检查点增加 schema2 的设置/状态；普通模式保留 schema1。
旧 schema1 默认模式可继续恢复，但不能据此凭空重建 native NSAME。恢复时核对设置并恢复 RNG/MC 状态。
这是已有驱动的可选模式扩展，不新增控制框架，不改变其它 SSW 变体的默认。
原版外层 MD 强制接受等覆盖规则不属于本次接口，不能以该接口宣称整个 LASP make_decision 已复现。
原版整数升温溢出的受限域保留：域外明确终止，不引入未验证的截断或回退。

## 数值可重复性的前置检查

`mace-repeatability-20260918`，job1383387，1 V100，35秒 COMPLETED。
四个既有真实输入，各模式两个独立进程，每进程每结构三次清空 Calculator 缓存后的新 E/F，最多48次，全部成功。
比较当前模式与 torch.use_deterministic_algorithms(True)，固定 float64、单线程、CUBLAS_WORKSPACE_CONFIG=:4096:8。
当前模式同点力有约1e-15～4e-14差异；确定性模式同一调用序号跨两个独立进程完全一致，
但最初几个调用之间仍可能有约1e-14差异。因此不宣称 Calculator 对调用历史逐位无关，也不将其唯一归因到具体算子。

下一判据为完整首个 SSW 外步：`ssw-deterministic-repeat-20260918`，job1383430，
两个独立进程各跑 C60×2、Cu55、水15各一个完整外步，最多24000搜索请求，不改变算法参数。
以完整 E/F 请求账本、接受结果和真实落点相同为重复性证据；该检查不比较搜索优劣。

## 实现验收

必须覆盖：显式原版模式的 RNG 消费、NSAME 变化、失败落点不调用 MC、合格拒绝落点保留、
连续与拆分恢复一致、旧检查点兼容及错误设置在 PES 计算前拒绝。
原指令函数测试与真实体系 E2E 分别报告。实现正确不自动意味着比普通 Metropolis 更好。

首个完整外步重复检查已完成：job1383430 COMPLETED，2分36秒。
四体系每条分别137、554、1152、1734搜索请求，重复两次共7154搜索请求；另16次独立落点/初态复核全部合格。
四对完整请求账本逐字节相同，结果对象与资格检查也相同。证据：`ssw-deterministic-repeat-20260918/analysis.json`。
这是同一节点、相同调用次序、同一环境中的两进程重复证据，不扩大为跨硬件或任意恢复历史的逐位保证。
因此后续当前环境的配对开发实验采用此明确记录的确定性设置；不修改通用 ASE Calculator 的全局默认。

## 接入实现与当前验证

共享 run_ssw/run_ls_ssw 与 run_native_ls_ssw 已支持显式 mc 设置。
针对性验证：原指令 MC、SSW 驱动、检查点共44项通过；native LS 17项通过。
补充驱动级拒绝落点保留测试后，test_ssw_native_mc.py 为7项通过。
失败真实淬火、下坡无条件抽样、拒绝落点保留与当前态不变均直接覆盖驱动路径，
不是仅以独立 MC 函数测试替代集成覆盖。
使用修改前源码实际写出的 schema1 pickle 做兼容检查：默认恢复成功，
误用于 native 模式在0次PES请求前拒绝。证据 native-mc-legacy-checkpoint-20260918/verification.json。

真实体系接入验证 job1383607：四起点各4外步，单条最多6000搜索请求，
最多20次独立复核，一张V100、30分钟作业上限。源码、完整配置与输入已冻结于
native-mc-materials-20260918。目的为决策与轨迹接入资格，非搜索效率排名。

独立代码审查发现 MC 域外错误后仍更新 LS，可能被次生 LS 错误覆盖状态。
现明确 mc_failed 为终止边界：跳过 LS 更新，保留真实落点、成本和旧状态。
新增共享驱动+native LS 的故障回归；最终原指令/驱动/检查点/native LS 六文件检查为63 passed。
真实 job1383607 的源码快照在此错误路径修复前冻结；其 maxtrap99999、四外步配置不会触发该升温域外路径。
不得以本批正常路径验证代替故障回归，也不覆盖冻结源码。
