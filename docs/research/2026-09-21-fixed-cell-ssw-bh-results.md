# 固定胞 SSW / ASE BasinHopping：本轮结果与下一决定

目标是检验独立SSW的搜索效用，排除最终局部优化器不同造成的混淆。本轮不是LASP数值复现，也不证明算法普遍排名。

[协议/源码/输入/原始结果](../../research/ga_ssw/evidence/fixed-cell-ssw-bh-20260921/README.md)：Cu55团簇、brookite48周期TiO2，各seed11/29，SSW与ASE BH各一臂。OMAT-small/omat_pbe/float64；共享Safe-total history500、true fmax0.03 eV/Å、400局部迭代；SSW bias fmax0.1、最多25 Gaussian；BH dr0.5Å；MC150K。Cu55 direction_only、周期translation_only。原版程序不参与这次搜索。

## 结果

能量变化均相对各臂已淬火初始结构，单位eV；minima计数含初始、含MC拒绝，未作结构去重。

|体系/seed|SSW实际calculate|BH实际calculate|SSW最低ΔE|BH最低ΔE|SSW/BH返回minima|
|---|---:|---:|---:|---:|---:|
|Cu55/11|5258|5934|-0.001204|-0.000927|10/66|
|Cu55/29|5277|5935|-0.000956|-0.000972|10/65|
|brookite48/11|5365|5938|-0.000986|-0.000916|9/62|
|brookite48/29|5374|5945|-0.000779|-0.001052|9/55|

这些meV级改善不能支持SSW或BH的低能发现优势；只能确认在本协议和预算下，相对各自初态仅获得meV级下降；是否接近物理低能结构尚不能判断。实际成本前缀核查：四个BH最终最佳均在对应SSW实际calculate上限之前发现，且是已独立复核的同一个quench事件；缓存差异没有隐藏一个相反的最低能结论。前缀不宣称精确等成本。

所有34次完整SSW逃逸都用满25Gaussian，4个最终尝试被总预算截断。没有低能早停；因此本轮现象不能归因于“过早真实能量退出”。返回阶段记录中的旋转请求占每臂6000请求的约73–77%，偏置淬火约11–17%，真实淬火约3–4%；中断阶段成本仍计入总账本，不要求这些不完整分类相加等于总数。

不能反过来说“两种方法全程只重复原结构”：全部候选相对初态的最高能差，Cu55 SSW为0.0027/1.352eV、BH为4.712/5.112eV；brookite SSW为1.965/1.690eV、BH为13.242/14.588eV。连续的排序原子对距离谱也有变化。它们表明曾产生不同几何/能量的候选，不证明新basin数量、路径、物理稳定性或有用的低能覆盖。BH候选更多/更高能不是自动更好。

Cu55最佳态在沿用的3.0/3.2/3.4Å距离图上均连通；brookite最佳态最小Ti–O约1.869Å、Ti–Ti约2.974Å、O–O约2.515Å。仅作完整性诊断，不代替Hessian、化学身份、MLIP适用域或DFT验证。

## 决定

1. 保留此协议作为跨团簇/周期的数值、成本和状态管理证据；不提升默认、不据meV级差别排名。
2. 不围绕这两个低能起点调宽度、步数、温度或新增组件。先从已有examples/既有随机输入中选择有明确优化困难的初态；后续对照仍锁定输入、后端、预算、资格与唯一变化因素。
3. 旋转成本在两类体系均占主要部分，值得保留为共同问题；但此前便宜的原版启发方向未表现一致的有用落点收益，不能仅凭省调用替换默认。
4. SSW/LS/GA使用入口只读审查未发现新的常见工作流阻塞；这是静态核查，不是本轮对LS/GA重新端到端验收。VC/RC和完整Q库继续暂缓。
