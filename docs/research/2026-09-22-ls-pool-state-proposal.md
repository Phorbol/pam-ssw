# 已批准：LS 与池重启的最小状态契约（2026-09-22）

目标是接通用户已要求的“合格落点入池、从池选择下一个起点”与已有LS内核，不宣称池策略比MC更有效。当前 `run_ssw` 明确拒绝 LS+starter_selector，已有池试验未显示一致收益；本次不新增评分项、MACE特征或默认策略。

用户于2026-09-22批准“重启时重新初始化LS”，现按以下最小状态契约实施。先前批准仅覆盖固定胞SSW连续方向与显式重启，后续LS状态规则留待讨论。最新旋转与LS两组对照均为混合收益，因此结束旧C60初态的参数探索；接口组合与科学效率分开验收，不把新组合预设为解药。

## 已确认的约束

LS封存的邻居和参考距离属于生成它的几何。池重启到另一结构后不能直接沿用旧frozen potential。NativeLS还持有元素对强度、旧键数、响应、步计数和save/restore笔记；paper LS持有强度及响应历史。同一结构在不同历史下的LS提议分布可以不同，不能仅凭archive entry推断唯一状态。

## 推荐：显式重启重新初始化LS，连续走保持状态

- 选择器返回None或当前观察索引：保留现有连续方向与LS状态，行为不变。
- 选择另一合格观察索引：先按既有LSSettings/NativeLSSettings在选中结构上重建初始冻结势和新响应控制器，成功后提交起点切换；旧LS强度/响应历史不跨跳转传递。NativeLS的局部步计数归零，整个SSW的外步、RNG、累计成本和既有MC处理不归零。
- 此次外步已发生的真实能量响应和LS更新照常记录；随后重启事件明确写出LS重新初始化。新起点来自已合格minima，不重复真实初始淬火；下一外步仍执行正常软面预淬火，所有实际调用计费。
- 重建失败先不提交新当前态/新LS状态；保留已完成记录和费用并明确报告失败，不悄悄选择别的seed或把旧冻结势当新势。
- 复用现有初始化和方向重启逻辑，局部抽取LS初始化函数以避免两套公式。公共调用仍为现有run_ssw(ls=..., starter_selector=..., selector_rng=...)；不新增可调权重或多种重启参数。仅第一版固定这一显式语义。
- 范围：已有无约束固定胞入口；LS+pool checkpoint继续拒绝。此项不改变存储格式、不把约束/VC/RC或GA状态一起重设计，不提升池策略默认地位。

这是可解释的独立重启基线，不是最优策略定理。代价是池跳转频繁时LS的累计自适应历史会被丢弃，可能影响收敛/效率，必须记录并验证；收益是每个重启分支有明确状态来源，无需新per-basin状态仓库或跨几何强度转移公式。

## 备选

1. 按池分支保存LS状态：能保留各分支适应过程，但“结构条目”不等于“搜索分支”，同一近似条目可以有多个历史；需重新定义archive/branch身份与checkpoint责任，范围更大。
2. 全池共享强度表，仅重新冻结几何：保留累计适应，但响应会跨不同局部环境传播；旧/新键数归一化、周期笔记和历史归属需要明确新控制器语义，不能当简单复用。
3. 继续不组合：独立SSW池和LS路径各自可用，零实现风险，但用户要求的LS池搜索仍不可用。这是合理备选，并非必须为了获得更低能而叠加组件。

## 最小验证与停止条件

先做确定性的同状态回放：透明选择器保持原轨迹/LS状态/费用；实际跳转冻结几何确属新起点；当前索引选择不重置；LS初始化失败不产生半切换；既有非LS池与非池LS回归保持。随后在已有C60/MH-1和周期TiO2/OMAT-small保存输入做有界接口验证，单独核查实际重启、LS响应、落点独立力和周期边界；不以通过测试或落点数证明搜索收益。

不调整强度/宽度/评分权重，不升级默认。性能实验另按固定协议设计；若没有额外科学信号，停止该组合的效能探索，不继续堆叠特征。池持久化和MACE表示仍由各自明确契约决定。
