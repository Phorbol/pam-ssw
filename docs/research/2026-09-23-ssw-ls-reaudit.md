# SSW/LS 代码与证据复审

日期：2026-09-23。范围：`ga-ssw-behavior-parity` 当前源码、主线及近期 LS 报告、已归档 LS-SSW 论文抽取文本和指定 LASP ELF 反汇编。只读检查；未改算法、未运行计算或作业。这里区分会改变搜索轨迹的未闭合语义，与代码已实现但科学收益仍有限定的机制。

## 当前判断

不建议为 SSW/LS 增加新参数或改默认。LS 初始化、响应更新、预淬火策略、周期镜像及池跳转重建均已实现，并有跨 OMAT-small、MH-1/omol、EMT 等实际路径证据。本次补核了 C60/MH-1 的两条 60,000 请求 NativeLS 轨迹和 OMAT-small 水15结果，故不能再把证据概括成“仅 C4H6/GFN2”。目前有证据的工程负担集中在真实势最终淬火的 maxiter 失败及其请求成本；C60 的响应自适应已接近目标，但轨迹没有覆盖约100步后的稳态/振荡阶段。组件收益仍混合，且完整策略对照不能定位到外层调度。

## 优先问题

### 1. 已观察到的主要失败成本在真实势淬火，不在 LS 软面准备

**科学影响。** 若偏置落点在真实势淬火预算内未收敛，LS 是否产生有用候选便无法从该步判定；把这些情况称作软面失败会错误地归因于 LS。

**现状与证据。** OMAT-small 水15 recovered+NativeLS 开发对照中，seed11 返回0个合格新落点，seed29 返回10个；seed11八次失败均为真实淬火达到300步 `maxiter`，不是软面预淬火或线搜索失败。相同保存起点的既有真实淬火回放中，Safe-total/history10 为4/5起点力合格，history500 为5/5；但仅五起点且不保证重现旧整条轨迹，不能据此改通用默认值。见 [OMAT-small 衔接结果](2026-09-17-recovered-ls-integration-results.md) 的“相同起点的真实淬火对照”。

**竞争解释。** (a) 水15问题主要是300步真实淬火预算/历史长度使部分落点未完成；(b) 方向与 LS 组合生成了难淬火结构，最终优化器设置只是暴露了这种结构差异。现有相同起点回放表明优化器历史能影响资格结果，但样本太小，尚不能把整条轨迹差异归到其中一层。

**当前决策。** 把真实淬火 `maxiter` 作为现有失败成本的归档/解释重点；不得把 history500 的小样本结果升级成默认或据此要求扩预算。禁止新增 GFN2/xTB 工作。此前关于 native MC 后键数指针的有限反汇编问题不列为当前优先项：没有观测到由它造成的失效，有限 parity 不自动构成有价值的科学工作。

### 2. C60 响应适应已接近目标；尚未采到的后段不是当前已证实故障

**科学影响。** 论文报告 penalty response 通常约在100个 SSW steps 内接近目标。若轨迹在显著偏离目标时就结束，可能缺少评价适应规律的证据；若已达到目标附近，则不能仅因未完整跑到100步就假设算法缺陷。

**现状与证据。** C60/MH-1 计划固定 `presteps=100, cycle=100, ratio=1.100000023841858`，由 Fortran NINT 得到 `nsoftstep=110`，所以这个配置不会进入 `save_zero/restore` 周期支路。17093、17094分别完成70、83个外步；71、84条更新序列（含起始更新）的 response 从4.615、4.492 meV/atom升至19.709、19.920，目标为20；全部资格字段为force，`q=1`，没有 step-limit 释放，亦无 `save_zero/restore`。对应 60,000 请求下的 C60 组合结果见 [2026-09-22 报告](2026-09-22-recovered-rotation-ls-results.md)、[plan.json](../../research/ga_ssw/evidence/c60-recovered-rotation-ls-prospective-20260922/plan.json)、两个保存的 [result.json](../../research/ga_ssw/evidence/c60-recovered-rotation-ls-prospective-20260922/c60_17093-seed17093/result.json) / [result.json](../../research/ga_ssw/evidence/c60-recovered-rotation-ls-prospective-20260922/c60_17094-seed17094/result.json)。论文位置为 `literature/215.txt:320` 附近的 Sec. 2.3 文字（反馈典型约100步接近目标）。

**判定。** 这两条轨迹在70/83步已接近20目标，未观察到适应失败；“典型约100步”是论文描述，不是必须达到的验收阈值。后期是否轻微振荡确实未采样，但现有结果没有显示这一缺失会解释两初态一好一差的搜索结果。按当前停止决定不再为此追加长算，也不为追求 native 周期分支而改参数。

### 3. 组件收益混合，不能由当前结果定位到外层调度

**现状与证据。** C60/MH-1两初态各有同输入的无 LS 参考和启用 NativeLS 轨迹；LS 对 seed17093 使最终 best 高约2.204 eV（更差），对 seed17094 使其低约10.193 eV（更好）；均未成目标笼，外步70/83。水15/OMAT-small 的 recovered+NativeLS 两种子为0/10个合格新落点，seed11的失败成本集中于真实淬火 maxiter。更早 C4H6/GFN2 的同预算前缀也显示连接图覆盖和能量结果混合，但不能替代当前 OMAT/MH-1 证据。主线不应据此宣称 LS 一致收益、无效或由外层 GA 调度导致。

**竞争解释及边界。** (a) LS 物理改写局部势后改变候选质量；(b) 附加软面淬火和真实淬火的费用/失败、种子以及方向策略共同造成表观差异。现有两种子完整策略结果无法识别各因素贡献；尤其不能把混合结果定位成 GA/外层调度问题。已完成的同起点真实淬火回放能说明优化器历史影响合格率，但仍不足以拆解整条搜索因果。

**当前决策。** 保持可选机制和参数，不加新任务/种子来追逐单项收益。后续主线工作优先从已有 OMAT-small 失败轨迹与账本里解释真实淬火的失败/成本；如需新验证，遵循用户最新指定的模型边界和主线安排，不新增 xTB/GFN2 任务，也不把这一对照扩为外层调度归因实验。

## 已实现项和不应重开的事项

- 论文 LS 解析力/冻结键几何、native 派生状态转移、池跳转后重建 LS、checkpoint 及预淬火参数拆分均已在代码中；相关代码/接口回归已做。不要把“与 LASP 的所有调用细节尚未闭合”写成这些机制完全未实现。
- `periodic-images` 已是显式选项，有短胞 Cu/Al EMT 诊断及 rutile/anatase OMAT-small 完整生命周期证据；默认仍为 `native-mic`。这些结果验证特定几何和执行链，不证明材料搜索收益或任意体系等价；见 [周期多例结果](2026-09-12-native-ls-periodic-results.md) 与 [周期 TiO2 生命周期](2026-09-20-native-ls-periodic-lifecycle.md)。
- 论文/原版参数不是跨势面通用推荐值。现有 C4H6 结果明确不把 GFN2 轨迹叫作 PBE 复现；不应通过逼近论文中的单个数值而新增未经验证默认值。
- Native MC 后键数更新几何的静态调用链边界仍记录在旧 audit 中，但未观察到对应真实失败。本轮不把有限 native parity 作为优先缺口，也不重新启动已停止的指针生产者反编译支线。

## 决策建议

保持算法与默认配置不变。当前最有证据支持的改进方向是已观察到的 OMAT-small 真实淬火 maxiter 失败/成本解释；C60 两条 NativeLS 轨迹的响应已近目标，未显示适应阶段是当前瓶颈。两种子结果对 LS 收益仍混合，不能定位到外层调度。无需为了补足 native 调用细节而重启反编译支线，也不追加被停止模型上的搜索。
