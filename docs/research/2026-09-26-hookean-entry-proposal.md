# 原子对Hookean自动入口：供用户决定

现有手动surface组合已用Cu13/EMT验证，见
[780次调用的结果](../../research/ga_ssw/evidence/hookean-composition-20260926/report.md)。
下一项不是新算法或重构全部SSW，而是决定是否正式接入ASE原生输入。

推荐最小方案：run_ssw接受Atoms上的原子对Hookean，复用已有规范化和surface包装；
在现有checkpoint保存规范化约束配置，恢复时先核对、再改RNG/调用PES。
旧无约束调用、旧checkpoint和默认值保持不变；旧文件不得静默加入新约束。
所有阶段的目标明确为V+U，输出明确约束身份，不把它当裸V极小值。
重复绑定同一包装器不重复加势，不一致的双重包装显式拒绝。

只限非周期、原子对Hookean与完整固定胞流程。固定点/平面不满足同样的刚体不变性；
FixAtoms/slab仍走现有constrained入口，不借此统一VC/RC或引入新几何框架。
不预设k、距离、原子对网络，不改变C60验收，不因接口可用就开启新C60测试。

备选：保持本轮已验证、已写入README的显式surface组合，不改checkpoint。
约束配置一致性继续由调用者负责，与现有Calculator契约相同。

实现验证：旧无约束轨迹不变；相同约束连续/恢复记录/RNG/方向/费用一致；
配置不一致在零PES前拒绝；ASE直接能量/力匹配且不双计；旧格式兼容；
之后用一条实际池重启路径核验组合。不以此声称成笼成功率改善。

讨论依据：项目AGENTS.md第8节的重要公共接口/持久化设计条款。
此处触及输入语义和保存格式；本轮只完成既有接口验证和文档，未实施扩展。
