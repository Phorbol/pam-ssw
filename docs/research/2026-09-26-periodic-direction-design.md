# 周期固定胞局部方向与记忆：已批准的最小几何契约

用户已批准独立周期几何方案；主agent整合、Luna分工实现。

目标：补齐独立ASE SSW的周期局部选轴/分组/阶段记忆，使同一晶体不同合法晶胞
表示不改变物理搜索定义；可接固定基底。不是复刻未闭合的原版周期轨迹，也不加入VC。

## 依据与问题

native c1范围筛选调用周期get_dist，c4连通组也用周期成键距离；见
native-global-random-workspace-audit.md和2026-09-17-c4-group-route-review.md。
c6局部叉积的映像与阶段记忆跨胞规则仍未恢复。现有Python控制器明确是自由簇，
非周期直接相减、质心/转动投影不能迁入晶体。不能删PBC guard后就宣称支持。

## 推荐方案

在现有recovered_direction入口新增显式周期几何模式，默认仍为旧非周期模式；
将几何运算集中在小型周期辅助模块，不复制SSW主循环。

1. 局部距离、成键图和轴使用固定cell/PBC下的ASE周期几何，明确每一端点的映像。
   c6在选定轴第一端点的同一局部图中构造叉积，不对三个向量分别任意MIC。
   成键跨胞不等于可旋转整个无限网络；同连通组沿既有c4规则回到原子对方向。
   分组规则/已有阈值保留来源，不新增经验半径。
2. 优化坐标和Gaussian中心始终保持连续未包裹坐标；阶段历史是这两者之差。
   不对实际历史位移再做MIC，也不要求历史小于半胞；Calculator需遵守ASE不修改
   输入坐标的契约。初态逐原子平移整数晶格向量属于表示变化，局部方向应等价。
3. 无约束且目标整体平移不变时复用现有平移投影；固定原子/外部锚点则只投影
   到活动坐标。不删除晶体整体转动，不从PBC自动推断外部势平移不变。
4. checkpoint保存/核对方向几何模式与cell/PBC；保存现有方向状态和连续坐标。
   旧格式保留；禁止把旧非周期方向状态静默按周期模式恢复。明确模式切换要重新启动。
5. 同时覆盖3D bulk与二维PBC固定基底的几何契约；首轮真实论文材料为bulk。
   slab在有来源输入/明确目标落实前只标实现检查，不能声明论文级验收完成。

精确等距镜像的选取、原子对最短轴退化及周期群的成分表示，需要在实现检查中
用晶体对称输入验证；失败显式记录，不能靠随机回退掩盖，也不增加“碰运气”阈值。

## 备选与取舍

A 推荐：独立周期局部几何+连续记忆。可与ASE任意E/F后端结合，优先获得明确定义
的功能；承担周期像与状态身份的代码/验证成本，不宣称native parity。
B 先继续恢复原版所有周期映像/调用规则，再实现。减少设计偏离但目前没有完整证据，
时间边界不清，并不保证原版的所有细节有益。
C 保留现有全局周期方向，单独增加S1梯度。可能更小，但不关闭局部选轴/完整方向
记忆缺口，故不将其当成A的替代完成。

## 实现与测试顺序

1. 周期几何纯函数与失败回归：合法逐原子晶格平移、非正交cell、二维PBC、固定原子，
   同一个局部图、方向投影和跨胞连续历史。旧非周期随机流与数值行为不变。
2. 接入已有controller/driver/checkpoint，不改旋转器、优化器、Gaussian或LS公式。
3. TiO2 rutile/anatase文献结构+brookite48机制面板，MACE-OMAT-0-small。
   初步用已有全局方向为对照，覆盖多Gaussian、真正落点与连续/分段恢复；每个
   保存端点独立复算原始目标的力/能量/约束。先测事件成本，再冻结多seed效果预算。
4. 实现验收要求每条路径实际执行局部方向与历史更新，表示等价且恢复正确。
   效果验收另报相同总请求下的有效独立极小值、目标结构事件及全部失败开销；
   返回多帧或低力不构成成功。固定胞结果不声称变胞相变复现。
5. 新功能验收前不默认启用，也不凭TiO2三个多晶型宣称泛化完成。追加异组分案例
   依照主线计划及明确科学假设，不开展自动无界扫描。
