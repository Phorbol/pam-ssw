# VC paper cases: evidence and discriminating pilot

Date: 2026-09-26. Scope: source audit and an executable-first bounded pilot plan for testing whether allowing the cell to move **during escape** contributes beyond atomic escape followed by a full-cell true quench. This is a mechanistic test motivated by Shang, Zhang & Liu (2014), not a demand for function-by-function native parity.

## Decision question

At matched PES, initial structure, stochastic protocol, true full-cell quench, and total calculator-call budget, does adding cell participation to the escape stage increase the rate of qualified, structurally distinct minima or phase changes? The paper supplies a hypothesis candidate: cell-direction escape plus fixed-cell ion relaxation, periodically interleaved with fixed-cell atomic SSW, then full atom+cell quench. It does not establish that this schedule is superior to the clean control “atomic SSW escape, then the same full-cell quench.” Compare those two mechanisms only. A joint atomic/strain direction can be a later, separate arm if its additional mechanism is isolated and justified; do not fold it into this first contrast.

## Executable-first cell-mechanism pilot (prepared; not run)

1. **Separate reference-quench gate:** Quench the sourced 12-atom rutile input once with the frozen OMAT-small model using the existing `cell_quench`/Safe-total path. The gate is `fmax ≤0.03 eV Å⁻¹` and `max(abs(stress + pI)) ≤0.001 eV Å⁻³` at p=0, followed by an independent fresh E/F/stress call at those same limits. Save and share that exact qualified geometry as both arm inputs. Gate calls are reported separately. Stop before either arm if the quench or fresh certificate fails. The 0.03 force threshold is inside the requested 0.01–0.05 range and matches the existing periodic SSW material protocol; 0.001 stress remains the existing physical cell threshold.
2. **Matched cell-on/off contrast:** Arm A applies five cell-direction cycles with fixed-cell partial ion relaxation, then performs one fixed-cell atomic SSW climb and a full atom+cell true quench. Arm B performs the same fixed-cell atomic climb and the same full atom+cell true quench, with no cell cycles before escape. Repeat for two outer steps so the study includes repeated proposals; here atomic SSW runs on every outer step in both arms, so this is deliberately **not** the paper's λ=2 cell-only / cell-plus-atomic interleave. Reuse the current `cell_direction`, `atomic_climb`, `cell_quench`, Safe-total optimizer, and lattice-step helper from `block_ssw.py`; research-level orchestration only, no core API change. Both arms use the same OMAT-small/PBE model, source geometry, 300 K Metropolis rule, 0.6 Å atomic width, ten Gaussian cap, pressure zero, 5 Å true-quench metric, 0.03 eV Å⁻¹ physical force threshold, 0.001 eV Å⁻³ stress threshold, and Safe-total L-BFGS with memory 500. Cell steps use the paper-scale 0.15 lattice Frobenius displacement and five cycles; these are paper-inspired settings, not recovered native parity.
3. **Pairing and budget:** Use independent per-step RNG streams for cell motion, atomic SSW, and the MC draw. Paired arms start with the same atomic RNG state and same MC draw at each step; resulting physical atomic directions can still differ after cell motion changes the geometry. The old 3-step rutile material traces cost 1,259 total/388, 438, 432 calls for successive outer steps (global direction) and 1,032 total for the local-memory variant; they used a different fixed-cell solver and are only a lower-cost reference. A separate joint-VC rutile step cost 173 calls plus two fresh checks. The block cycles add costs absent from both references. Therefore cap each arm at **6,000 counted E/F/stress calls and 600 seconds**, with a separate reference-gate cap of 300 calls/300 seconds and up to two independent fresh endpoint checks per arm outside its cap. One paired seed, two full outer steps requested; maximum is 12,300 search/gate calls including the gate fresh call plus four independent endpoint calls, or 12,304 total. The prepared one-GPU scheduler request is 30 minutes. A request or wall cap before the two full escapes is **censoring**, not a failed mechanism result. All cap hits, failed proposals, and partial work remain saved; no outcome-dependent retries or extension. Preflight history and the unplanned login-node check are recorded in [`preflight-record.md`](../../research/ga_ssw/evidence/vc-paper-panel-20260926/preflight-record.md).
4. **Decision boundary:** Primary readout is whether each attempt reaches a fully cell-quenched, physically certified landing; also record enthalpy, cell volume/strain, atom/cell stage calls, and periodic structural identity against the common start. Report attempt/censor/failure denominators and costs separately. If the pilot is censored before both arms get comparable completed escapes, it answers feasibility/cost only. A completed one-seed pair is still development evidence; no observed gain means “do not expand this case on current evidence,” not “delete the general cell mechanism.” Any larger seed panel or resource spend requires the root's review of these outcomes.

Runner: `research/ga_ssw/run_vc_mechanism_pair.py`; the CPU Cu/EMT preflight is `tests/research/test_vc_mechanism_pair_runner.py`. The prepared, not submitted, GPU entry point is `research/ga_ssw/evidence/vc-paper-panel-20260926/run.sbatch`.

## Explicit unknowns and scope limits

- `vc2014-author.pdf` and extracted text are the 12-page typeset paper (SHA-256 `21bebe8ff58de8c94205c13d93d2722c55fd0ab0cc70a9db15396796b06f1bf4`). The publisher-linked SI exists according to the indexed page but is not in the local record; candidate URLs failed or could not be verified. No exact 2014 SI coordinate path is therefore asserted.
- LJ truncation/long-range convention is not disclosed in the main text excerpt. LJ pair potential, reduced units, PBC, random initialization density, cell lengths and key search parameters above are reported; a specific cutoff is not.
- MA coefficients and precise implementation convention are not recoverable from the 2014 paper excerpt itself (the paper cites Matsui & Akaogi 1991). No coefficient table or source implementation was located in the supplied artifacts; do not invent it.
- The available TiO₂ SI coordinates belong to a separate 2017 source. They provide a reproducible material input for a new OMAT-small test, not the 2014 MA reproduction.
- Paper-native coordinate/sign ambiguities and exact block indexing are documented in [`vc2014-native-crosscheck.md`](vc2014-native-crosscheck.md). They do not block the independent mechanism comparison above and do not turn it into an exact schedule reproduction.
