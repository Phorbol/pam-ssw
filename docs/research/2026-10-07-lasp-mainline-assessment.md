# 回到 LASP：论文、二进制与独立 ASE 实现的阶段评估

本轮依据用户要求重新排序。评估基线为研究工作区
`research/c60-local-defect-qualification` 的 `06edc060`；同时读取已有 LS、VC、
优化器分支产物。只复核已有论文全文、源码、反编译记录和实验，不新增 PES、
作业或算法。历史实验结果不是这一提交的新版本性能测量。

## 目标与阶段

目标仍是独立 Python/ASE SSW-like 算法：吸收有物理/数学依据、能够消融且有效的
LASP 设计。既不以全部开关一致为验收，也不把公式、接口或单次小力落点当全局
搜索成功。目前是研究实现及效果验证阶段，不能宣称完整复现或总体优于 LASP。

分支集成也未统一：本轮检查 `merge-base --is-ancestor`，LS面板 `5fb6a0c`、
VC面板 `cfcce44`、优化器面板 `56bfc79` 均不是当前 HEAD 的祖先，GA分支
`01be86e` 是。不能由非祖先直接推断每项功能都缺失，但不能把这些分支的实验
合称当前同一版本已通过的验收。选定研究配置时需核对实际导入路径与必要差异，
而非为了整合全部历史实验机械合并。

## 已吸收的原版细节与不能机械复制的部分

1. **CBD与方向记忆。** 已依据论文和 caller/指令恢复预旋转、偏置/非偏置阶段、
   重入历史重置、旋转限幅等数值控制；局部方向组合已有 pair/group 和上一偏置
   阶段实际位移记忆。并非只有标准 dimer 或每次独立随机方向。欧氏投影与 native
   block 度量仍须显式区分，不能叫全状态数值等价。
2. **偏置与释放。** 原版87°高度控制、固定宽度、有限位移及下能量退出已有证据。
   Python 仍要求能量/力一致，并在裸 PES 上独立淬火和判定落点。
   [函数指令探针](native-addgaussian-instruction-oracle.md)观测旧 Gaussian 力重复累加，
   但完整 caller 是否补偿未闭合；不复制该 E/F 不一致，也不据此宣称原版全程序错误。
   [释放边界](native-release-current-gap.md)仍有 maxoptstep/停止标记及对象域未闭合，
   不能把 Allopt 名称或退出标签等同真势收敛。
3. **LS。** [推导与控制律](2026-09-23-ls-mechanism-and-budget.md)确认对势的径向
   Hessian 为正、切向为负；机制还包含预淬火几何变化，不能简化为所有谱都变软。
   native 邻居表、响应单位、元素表更新和 save/zero/restore 周期状态已进入实现。
   其强度控制不与论文逐步总幅度公式相同，不能只看相同目标响应就认为公平激活。
4. **优化器。** 已沿真实调用确认 LBFGS→MCSRCH→MCSTEP，并做过原机器指令的
   保存态对照。结果不支持普遍赢家；Safe-total 是独立数值选择，不是 LASP 移植。
   [比较与边界](2026-09-17-safe-total-versus-native-lbfgs.md)。
5. **描述符梯度。** S1/S2 数学/指令原语和已批准的显式模式库方案存在，但本工作区
   完整方向入口仍是 Q-off；不能把方案或原语称为公共 Q walker。S3–S6/完整选择器
   尚未闭合。已有强制 Q 对照收益混合，因此这属候选机制，不是必须优先补齐的清单。

## 关键实验：哪些差距确实存在

**LASP 同势 C60 对照已经做过。** [60000请求对照](2026-09-20-c60-long-budget-results.md)
中，原版用50Å大真空周期 MH-1/omol，Python 用孤立表示；所有原版请求做几何门，
另选24态×两表示共48次独立复算均通过等价检查。旧版 Python 两初态的最低合格能量
分别比原版高9.1864/25.7331 eV，双方联合目标均0/2。停止域和整个搜索配置不同，
这是有边界的整套配置差距，不是优化器排名。非周期映像旧无效对照不能混入。

[恢复CBD对照](2026-09-21-c60-recovered-rotation-long-results.md)随后使同两个开发输入
最低合格能量降低4.9213/14.7608 eV，120k总预算内旋转请求48280→16051、完整外步
117→182。仍比原版各高4.2651/10.9723 eV且未成笼；同时改变控制/停止规则，未隔离
方向质量与省下成本增加机会的作用。后来还有方向、约束等修改，不能把旧结果冒充
当前所有可选组合的同势复测。

**LS 有范围明确的正例。** [C4H6拓扑重分析](../../../ls-mechanism-panel-20260926/research/ga_ssw/evidence/ls-climb-depth-panel-20260926/topology-report.md)
四条各约26万E/F：SSW两seed新类4/4，nativeLS 10/8；跨seed合并6/10，LS多5类但
漏1类SSW发现的类。新类均未被150K MC接受，图类不等于经TS/振动确认的反应或稳定
异构体。[C60启用LS](2026-09-22-recovered-rotation-ls-results.md)一臂升能2.2036 eV、
另一臂改善10.1928 eV；不称稳定成笼收益，也不能据此说LS没有任何收益。

**VC 有真实验证但尚无搜索验收。** [SiO2面板](../../../optimizer-panel-20260926/research/ga_ssw/evidence/vc-sio2-heldout-panel-20260926/review.md)
Safe/SciPy/ASE各6次尝试，成本7174/8256/10759，落点6/6/5。
停止语义不同，且全部候选升能拒绝；不把短程调用差异推广为稳定优化器优势。
OMAT结果不称原文 BKS 相图复现，力/应力合格也不证明物理相身份。

## 本次排序与停止边界

1. **SSW 本体有效转移效率优先。** 在复用存档、锁定实际源码/配置之后，形成新版本
   可解释的同势对照；观察每付费 E/F 的合格不同盆地、回返、目标改善与失败成本。
   如出现差距，先依据阶段账本定位，再只改一个有论文/二进制依据的机制。
   不重复扫描旧C60两个开发输入，不直接加长LJ38或重开已收口单Gaussian调参。
2. **LS 并列主线、验收分目标。** C4H6覆盖与C60最低能/笼目标分开；保留已有正反
   数据，下一对照必须能区分 LS 实际响应/方向变化与纯粹额外成本。
   不再盲改响应增益，也不以新候选未被MC接受自动引出温度扫描或另一个池策略。
3. **VC 是下一层。** 保留论文block与独立joint的语义差别；在已有TiO2/SiO2及LJbulk
   材料上按物理相/结构目标验证调度，而非继续只争内层更严格 fmax。
4. **RC、GA、完整Q、AutoSella暂不扩展。** 当前尚无证据表明它们能比上述问题更直接
   推进验收。AutoSella审查保留为参考，本条替代其保存态比较的下一优先级。

仍可有价值地核查的二进制范围：实际差异涉及的多Gaussian释放交接、完整方向阶段
状态、VC cell/原子交替及度量。必须先有可区分解释的实际信号，不做无限反编译。
原生 LJ 势常数/截断尚未核实，不阻塞已有外接 ASE 势的固定胞对照与独立算法研究。
论文全文不是本轮阻塞；GA真实SI缺失仍记边界，但不因此暂停SSW/LS主线。
