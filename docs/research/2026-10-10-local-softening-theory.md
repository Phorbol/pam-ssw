## 结论先行

最值得深入的框架是**保守势变形下的机械稳定性与势垒响应**。它把LS分为三个
可独立测量的作用：直接改变切向刚度；预淬火导致驻点移动并改变真实PES；改变
相邻极小值和鞍点的相对能量及存在性。成熟的近邻理论是预应力刚度、非仿射弹性、
驻点延拓/折叠分岔和非线性塑性模。它们提供解释与判别方法，不自动给出搜索增益。

需要纠正“LS就是metric preconditioning”的过强说法。正定度量可以改变方向选择、
收敛速度和梯度流吸引域，但不改变原PES驻点、其稳定性指数或相同路径集合上的
真实能量minimax barrier。LS改变势能本身，能够移动/消除驻点，两者不是等价操作。

最有研究价值的问题是：**能否用有限且可计量的物理形变代价，让原本难以采到的
有用重排变得可达，并在撤掉偏置后保留下来？** “频率降低”“参与率升高”与
“响应到达目标”均不是这个问题的充分答案。

## 1. 符号、范围与原算法

在固定胞、固定允许自由度的光滑坐标x中，写

    F(x,a) = V(x) + a W(x),       a >= 0.

V是真实模型PES，W是一次外步内形状固定的LS势，含已冻结pair、参考距离和
相对权重；a为无量纲统一幅度，因此V/W均为能量。本文不是把当前跨步控制器
误写成连续延拓：跨外步更新邻居、r0和权重会改变W，下面分支关系不能跨该更新套用。

无约束簇须处理平移/转动；只在光滑局部坐标或正确约化Hessian上使用逆矩阵。
固定原子可直接删固定坐标。非线性约束/随位置变化的投影须包含几何项，不能
一概以P H P代替约束Hessian。周期MIC换支处不光滑。这里也不把质量加权振动
频率与笛卡尔优化曲率混用；给定正定质量矩阵时二者稳定性符号一致、数值不同。

论文Guan/Shang/Liu2024 [S1] Eqs.10–15及流程：构造排斥pair势 → 软面预淬火
→ 在软面做SSW → 去掉LS和Gaussian → 真面淬火/选择。当前
`pamssw/standalone/softening.py:FrozenBondSoftening.evaluate`和`LSResponseState`
实现指数势及真实能量响应；`ls_cycle.py`管理生命周期。
native元素表控制与论文幅度控制是不同控制律，参见
[既有实现/预算推导](2026-09-23-ls-mechanism-and-budget.md)。本轮不更换它们。
这里“local”首先指pair形式；原算法可以给全体系合格邻居都加势，并不等于只在
一个小区域施加载荷。将来若改为局域支撑，属于需要单独验证的设计选择。

## 2. LS对势与结构力学的预应力刚度

对一条pair，d=x_j-x_i，r=|d|，u=d/r，l=xi*r0，v=A exp[-(r-r0)/l]。
对相对坐标的二阶导严格为

    D = v'' uuᵀ + (v'/r)(I-uuᵀ)
      = (v/l²) uuᵀ - (v/(lr))(I-uuᵀ).

任意相对位移z的二次型为

    zᵀDz = (v/l²)|z_parallel|² - (v/(lr))|z_perp|².

第一项增加键长方向刚度；第二项来自已有pair力在横向运动中的重新定向，是
几何刚度/预应力项。Guest2006 [S2] §2–3推导了结构体系的对应分解。
将其用于LS是本项目的数学对应，不是该文研究过LS。整个体系可写

    Hess W = Bᵀ diag(v''_e) B + sum_e v'_e Hess r_e,

B是pair距离对坐标的Jacobian。不能要求真实MLIP自身也是pair可加；这里只
分解人为加入的W，真实多体Hessian仍完整保留。
加入W的瞬间通常净力非零，它并非刚度理论中一个独立自平衡的自应力状态；
预淬火后是V与W的合力平衡。因此借用的是切线刚度分解，不能直接搬用整个
tensegrity体系的prestress-stability定理。

两个有区分力的推论：

1. 同一pair只有在 |z_perp|² > (r/l)|z_parallel|² 时贡献负曲率。
   在r=r0、xi=0.2处，需要横向平方幅度超过纵向的5倍。不是所有键伸缩都被软化。
2. 此处tr(D)=v/l²*(1-2xi)>0。固定几何、未投影的单pair三维块平均曲率反而
   增加，但仍有两个负特征值。完整六维pair块trace为2tr(D)。不能将此推广成
   任意约束投影后的平均谱都变硬，更不能推广到预淬火后的谱。

这给出可证伪判据：若某模式被直接LS项软化，其pair横向贡献应足以压过纵向项；
若不是，就应在几何移动导致的真实Hessian变化中找解释。参与率本身无法区分。
xi控制纵/横贡献的比，不只是“势衰减得快不快”；0.2不是由上述推导得到的最优值。

### 自由团簇的一个严格限制：同号排斥无法自平衡

对自由、非周期、允许均匀伸缩的有限团簇，取d_i=x_i-x_center，并令
x_i(t)=x_center+(1+t)d_i。固定pair/r0，所有A_e>=0且至少一项为正，则

    dW(x(t))/dt |_(t=0) = sum_e r_e v'_e
                       = -sum_e r_e v_e/l_e < 0.             (D1)

因此grad W不可能为零。初态若是真实V的驻点，加任意正幅度LS后必不再是
原坐标的驻点。特别在r_e=r0_e、统一xi时，D1正好等于-S/xi，S=sum_e A_e；
论文的总强度本身也控制一个确定的膨胀方向加载。

这是一条直接的virial/缩放恒等式。用B表示距离Jacobian，自平衡要求Bᵀv'=0，
与d做内积即同D1矛盾。总力因pair作用反作用而为零，不等于每个原子力为零。
所以仅重新分配非负排斥pair权重，无法在这个自由团簇上构造完全不移动起点的
自平衡预应力。负权重、角度项、外部载荷或额外约束会改变问题，不能从此直接
建议加入它们；还需满足保守性、边界和真实有效性。

D1证明有膨胀方向的下降趋势，不证明实际位移是纯膨胀，更不证明必然裂解。
固定胞周期体系的均匀伸缩不是同一个允许自由度，不能照搬；受限体系须检查d
是否属于活动切空间。该边界也是为何不能从C60直接推断bulk的LS行为。

### 为什么“去掉膨胀力、保留全部软化”不是一个免费的修正

这是上述推导的进一步限制，不是已经采用的新算法。两个看似简单的补偿需分开：

1. 笛卡尔补偿 $\widetilde W=W(x)-W(x_0)-g_0^T(x-x_0)$ 在参考点梯度为零、
   Hessian不变，但一般破坏旋转不变性。沿旋转轨道$x(t)=e^{t\Omega}x_0$，
   不变势满足$r^TH_Wr+g_0^T\Omega^2x_0=0$，其中$r=\Omega x_0$。
   若补偿后仍不变且梯度为零，必须$r^TH_Wr=0$；原H不一定满足。
   因而不能将该补偿称为保留全部自由簇几何的纯预条件。某个旋转方向右项为零
   是例外，不能把“通常冲突”夸大为任意势/构型的无条件不可能。
2. 对每条pair改为$\widetilde v(r)=v(r)-v(r_0)-v'(r_0)(r-r_0)$，保留距离对称性，
   在全部参考距离处有$\widetilde v'=0$、$\widetilde v''=v''>0$。
   此时Hessian只剩正轴向项$B^T\mathrm{diag}(v'')B\succeq0$，原负横向预应力
   项恰好消失。离开参考构型后几何项可重新出现，不能宣称全局Hessian正定。
   指数势的这一补偿还有正线性长程尾，可能人工束缚解离路径。

这两例不排除更一般的自平衡多体/有正负应力设计；它们排除了“删掉原点力但
毫无代价保留原LS”的两个直接捷径。与Guest的平衡矩阵/预应力分解相容，
补偿分析是本项目推导，不冒充原论文结论。现阶段据此**不实施补偿势**，
先执行T1的同一势响应诊断，再核查T2通道；不能用新组件掩盖原机制尚未解释。

## 3. 驻点延拓与非仿射响应

设x(a)是F上的非退化驻点，g=grad W，H_a=Hess F。对grad F=0求导：

    dx/da = -H_a^(-1) g.                                      (T1)

局域加载可产生集体响应，因为H_a的逆一般非局域。这与Maloney/Lemaitre2006
[S3] Eq.1的非仿射响应结构相同；该文参数是外部剪切，此处是内部保守偏置幅度，
不能直接照搬其塑性统计结论。

在固定坐标图中，沿驻点分支的总Hessian变化为

    dH_a/da = Hess W + third_derivative(F)[dx/da].              (T2)

第一项是直接加势，第二项是几何重排后曲率的变化；它同时包含V和aW的三阶项。
对非简并归一化本征向量u_k：

    d lambda_k/da = u_kᵀ(dH_a/da)u_k.

近简并时应跟踪子空间，不能将任意本征向量旋转解释成物理模式突然改变。
“LS使模式更集体”可能来自模态耦合和几何迁移，单看Hess W不能证明。

## 4. 响应目标的确切含义：形变代价，不是势垒保证

沿同一稳定极小值分支，定义真实能量响应P(a)=[V(x(a))-V(x(0))]/N。
利用grad V=-a g和T1，得到精确局部关系

    P'(a) = (a/N) gᵀH_a^(-1)g >= 0.                         (T3)

对a>0、H_a正定且g非零则严格为正。小幅度有

    delta x = -a H_0^(-1)g_0 + O(a²),
    P(a) = a² g_0ᵀH_0^(-1)g_0/(2N) + O(a³).               (T4)

这将已有弱幅度推导扩展到同分支精确斜率。系数是对该加载形状的柔顺性；它
同时依赖模式刚度和g对模式的耦合。临近软模时，若g与其正交，响应不一定发散。

这支持将“给定形变能预算下的幅度选择”视为有物理含义的问题，却不能从中推出
论文目标Y普适、反馈系数1.8稳定或应该尽量靠近失稳。跨步重建W、跳支及有限
淬火误差均可能破坏该单调性诊断。未处理零模时逆矩阵不存在；若g与零模正交，
在恰当商空间或使用相应伪逆仍可建立关系。当前自适应外步不是在固定分支求根。

局域扰动若总形变能随系统尺寸保持有限，P会被N稀释；声学模/弹性长程响应可能
改变缩放，不能无条件声称1/N。应先决定控制的是局部事件代价还是全体系形变，
再研究尺寸归一化。不能把每原子常数目标直接解释成每个反应位点承受相同作用。

自由团簇还有一个无新拟合参数的诊断。令chi=gᵀH_0^(-1)g，d为D1的伸缩
方向；由H_0内积的Cauchy不等式，

    chi >= (dᵀg)²/(dᵀH_0 d) > 0,
    f_dil = (dᵀg)² / [(dᵀH_0 d) chi],  0 < f_dil <= 1.     (D2)

f_dil是线性响应H_0^(-1)g在span(d)上的H_0正交投影所占弹性能比例。它不是
欧氏位移比例，也不是“无用事件比例”；膨胀有时也可能帮助反应。其价值是区分
响应预算是否主要进入均匀伸缩分量。需HVP/线性求解或小体系Hessian，成本要
记录。T1随后在四个Cu13/EMT及C4H6/MH1结构上测得0.76–1.00，见
[机制读出](../../research/ga_ssw/evidence/ls-theory-20261010/mechanism-readout.md)。
仍不能据此宣称强加载或现有C60结果由膨胀主导。

## 5. 势垒响应与局部稳定性是两个问题

设m(a)、s(a)是持续存在的极小值/相连一阶鞍点分支，定义该鞍点的偏置势垒
B(a)=F(s(a),a)-F(m(a),a)。驻点包络关系严格给出

    B'(a) = W(s(a)) - W(m(a)),                              (T5)
    B''(a) = -g_sᵀH_s^(-1)g_s + g_mᵀH_m^(-1)g_m.         (T6)

H_s不定，二阶导无固定符号。即使m处曲率下降，也不保证目标通道B下降；排斥
势可能帮助某些伸长/扭转路径，同时提高需要局部压缩的路径。通道交叉时最低
势垒是多个分支的下包络，可能有折点。该s是否仍连接目标盆地也必须独立核验。

更强的结论是：**仅有minimum附近任意有限阶导数，都不足以一般地决定远处
势垒或最终落点。** 可在minimum邻域外加光滑紧支撑势包，保留邻域全部导数而
改变鞍点/通道。这是局部信息的数学限制；不应承诺用某个谱指标普适预测逃逸成功。

有限连续变形后还需撤掉偏置。突然撤去后落在哪个真实盆地，不由T1–T6保证；
缓慢卸载若一直沿同一非退化分支反向跟踪，就回到原结构。观察到不可逆落点才
说明经过了分支转换或跨越真实淬火吸引域边界，但仍须排除优化误差和解离。
因此不能未经测试就把“渐进卸载”写成改进，它也可能更稳定地回到原盆地。

## 6. 折叠分岔给出局部标度，不给有用反应保证

接近非退化saddle-node、其他模式可消去时，正规形可写

    F(q,a) = F_c - c(a_c-a)q + b q³/3,   b,c>0.

令epsilon=a_c-a>0，则q_±=±sqrt(c epsilon/b)，且

    lambda_min = 2 sqrt(bc epsilon),
    barrier = (4/3) c^(3/2) epsilon^(3/2)/sqrt(b).           (T7)

S3 §III讨论外部加载下的对应折叠结构。用于LS是条件化推论：对称性导致三阶
系数为零、多模同时软化、加载不耦合临界模或MIC非光滑时不适用。解离/整体膨胀
也可能先发生；临界性不是化学有用性的证书。

冻结几何下若H_0正定、K=Hess W，有

    a_frozen = -1/lambda_min(H_0^(-1/2) K H_0^(-1/2))

仅当分母为负才有正阈值。这不是重新平衡分支的实际a_c，因为T2的几何项未包含。
WQ的K半正定却能发生分支变化，就是不能以冻结阈值替代全过程的直接提醒。

## 7. 从最低谐波模到非线性塑性模

Gartner/Lerner [S4] §II Eqs.1–2研究方向z上的三阶局部展开

    delta V(s z) ~= kappa(z)s²/2 + tau(z)s³/6,
    b(z) = 2 kappa(z)³ / (3 tau(z)²).                      (T8)

这解释为什么仅选小kappa可能选中无用的软振动：非谐性tau同样重要。该文对象
是模型玻璃，不能直接推广到C60成笼或所有反应。三阶近似驻点也未必是完整PES
鞍点；tau接近零、距离过大、四阶项重要时b会失去意义。

研究价值是把“谱变软”与“非线性逃逸更容易”分开测量。先用已有方向的一维
力/曲率变化作诊断，不立即实现高成本三阶张量优化器。投影tau可由HVP差分等
方式估计，但差分误差和额外E/F必须计入，不能假定任意ASE Calculator支持三阶AD。
也不以更局域或更集体本身为目标：二者可能对应不同有效重排。

## 8. 度量预条件的边界

对正定M，广义特征问题H u=lambda M u等价于对称矩阵M^(-1/2)H M^(-1/2)。
合同变换保持正/负/零惯性，因此无法单独将正定minimum变为鞍点。即使M依赖x，
在驻点grad V=0处这个结论仍成立。原PES的驻点、能量及固定允许路径集合上的
minimax barrier不变；数值路径、模式排序与梯度流吸引域可以变化。

Packwood等2016 [S5] §II.B/C是原子体系度量预条件的成熟参照。它可以作为将来
隔离“数值条件数改善”与“势面改变”的对照；不能将其性能直接转移给LS，更不
能由这篇文献宣称当前Safe-total必须替换。

## 9. 一个更一般的设计问题：单位形变代价能降低多少势垒？

以下是基于T4/T5的局部线性—二次模型最优预测；不是真实有限幅度势垒的严格
上界，也不是已有新算法或原创性声明。
允许W由固定形状W_e按系数c_e组合。令G的列为grad W_e(m)，C=GᵀH_0^(-1)G，
d_e=W_e(s)-W_e(m)。弱扰动下

    true deformation cost = cᵀC c/2 + O(||c||³),
    barrier change = dᵀc + O(||c||²).

若C正定、d非零、不限制c符号，在cᵀC c<=2 E_budget下，线性化最优解是

    c* = -sqrt(2 E_budget/(dᵀC^(-1)d)) C^(-1)d.           (T9)

它把**加载的方向选择**和**加载强度**分开，并揭示按标准键能分配幅度未必有效：
加载之间通过真实结构的柔顺性耦合，作用还取决于目标鞍点。

不能直接把T9接进盲搜索：目标鞍点通常未知；C常为半正定，零空间可使局部代价
退化；原LS的c>=0约束会改变解析解；有限幅度还会换支。因此先在已知反应路径
上检验“现有LS是否沿着能降低该势垒的方向加载”，才讨论可低成本近似的指标。
仅学习MACE特征或加入评分项不能自动解决这些可辨识性问题。

若要设计新的Hessian修改，必须能来自可微保守势或明确的度量/算法操作；不能
只删去指数势的正径向项、保留负横向项，再假定原有能量和力仍一致。

### 单一加载形状的通道响应：不依赖人为幅度归一化

固定一个已验证通道、原点W形状，记$b=W(s)-W(m)$、
$\chi=g_m^TH_m^{-1}g_m>0$。由T4/T5，沿$a\to0^+$：

    delta B = a b + O(a²),
    delta V_m = (a²/2) chi + O(a³),
    -delta B / sqrt(2 delta V_m) -> -b/sqrt(chi).          (T10)

这个比值单位为sqrt(eV)，不是无量纲“普适质量分”。正值表示该特定通道在弱加载
下下降，负值表示上升；响应χ再大也不能改变b的符号。对W→cW、c>0，b→cb、
χ→c²χ，T10不变，避免仅把幅度调大就声称加载形状更优。这里用总形变能，不把
每原子归一化与事件代价混淆；χ=0、未核验连接、强加载/跳支不使用该表达式。

它是有已知鞍点时的诊断，不是盲搜索可直接计算的acquisition，也不要求每个SSW
外步求TS。T2a保留必要的端点Hessian和固定W，资格通过后可离线算此指标，无新
PES成本。要把它转化为未知通道上的在线算法，仍需独立假设及真实端到端消融。
