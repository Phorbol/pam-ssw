依据用户已经批准的[最小方案](2026-09-26-descriptor-direction-entry-proposal.md)。
本轮用户要求用论文真实案例测试；不重新设计描述符族、不新增默认方向策略。

## 任务与验收

- [x] 独立描述符模块：复用已核查S1/S2公式，显式参数、全原子梯度、周期完整邻域映像。
  不从核心导入research脚本，不使用MLIP特征代替源公式。
- [x] 现有方向控制器接入：每外步固定所选模式，每Gaussian重新求导，允许自由度投影，
  仍用现有CBD；关闭时不改变随机流。模式不可用保留失败，不偷偷替换方向。
- [x] 配置与外步恢复身份：新模式检查点让旧读者明确拒绝；旧空库配置与格式保持。
  使用现有schema包装模式，已批准范围内新增schema8；有约束入口相应版本保护。
  Hookean/shape已有几何限制不能因新包装绕过。
- [x] 定向验证：解析梯度独立差分、周期映像、自映像、活动自由度、关闭兼容与恢复。
  CPU节点运行已有相关回归；不在登录节点做PES。
- [x] 真实端到端开发验证：论文来源C60缺陷和TiO2几何，各Q-off/S1/S2，固定输入/模型、
  CBD、偏置与停止条件；上限每臂2外步、6Gaussian、3000请求、90秒。
  全组6臂最多18000搜索请求，终态cold复核另计且有显式上限；单V100最多30分钟。
  MH1/omol与OMAT-small分别用于分子和材料，不是论文原势数值复现。
- [x] 主agent复核代码/实际轨迹/失败账本，再更新主线和保留决定。

模块分工：实现子任务仅修改描述符、方向控制器及必要恢复校验/测试；案例子任务
仅准备研究runner/协议；主agent负责接口和源证据复核、冻结源码、提交与结果分析。
源论文案例提供结构与科学场景，诊断性模式参数明确记录，不叫原版默认或最优。
任何失败先定位公式、状态、方向求解或淬火层；不利用本面板调参数获得成功。

验收是完整可追踪生命周期和数值资格，不要求短程命中全局最小值，也不以
force合格代替结构合理性。若只完成原语/接口则明确不称完成端到端验收。
