# Fe7C3 frozen LS-quench diagnostic

This is a prepared, offline diagnostic for the four completed source arms:

```
evidence/fe7c3-80-ls-filter-comparison/comparison/{ls_all,ls_filter}-seed{7,101}/result.json
```

For each source result, the script selects the first completed outer attempt
whose biased relaxation reached the 300-step optimizer boundary.  A stage that
ended only because the source budget was exhausted is not selected.  The
selected chart reference, final failed point, complete Gaussian history, and
serialized `frozen_softening` are reconstructed exactly.  The local objective
is the physical periodic-cell E/F/stress surface plus the frozen Gaussian sum
and frozen LS contribution.  Thus this diagnosis preserves the source LS
forces, stress pullback, Gaussian centers/directions/widths/weights, and
source geometry; it does not change the physical input, LS parameters, height,
or width.

Each source failure gets one fresh failed-point check.  Each history arm uses
Safe-LBFGS with the existing history value (10 or 500), 300 iterations, 329
optimizer requests, and one reserved final fresh evaluation (330 requests per
arm).  The four shared checks plus eight history arms give a declared maximum
of 2644 energy/force/stress requests and 300 seconds.  Every paid evaluation
and the final fresh point are serialized with complete atoms and gradients.
The reported norm is the established VC norm, the maximum of the largest
atomic-force norm and the six-component cell-block L2 norm; the source
relaxation norm is retained separately for comparison.

`tests/research/test_compare_fe7c3_ls_frozen_quenches.py` only reconstructs a
small analytical case and the checked-in source record.  It does not load a
MACE model or execute PES work.  Running the diagnostic itself is deliberately
left to the parent review and resource plan.  Any result is a fixed-parameter
local diagnosis of these Fe7C3 failures and is not evidence of a new search
success or a default-policy change.

## Completed artifact audit

The completed job artifact is
`research/ga_ssw/evidence/fe7c3-ls-frozen-quench-history/`. The offline
summary is `frozen-quench-diagnosis/audit-summary.json`, generated by
`research/ga_ssw/audit_fe7c3_frozen_quench_results.py`.

All four shared failed-point checks matched the source full gradient L2 within
`3.0e-15`; each charged exactly one EFS request. All eight history arms have
one final fresh evaluation and 242–319 optimizer evaluations, for 2,435 total
charged EFS requests including the four shared checks, below the declared
2,644 cap. Seven arms ended at the 300-step `maxiter` boundary. The
`ls_filter`, seed 101, history 500 arm ended `converged` after 242 optimizer
requests. No arm ended with `request_limit`.

The final fresh VC norm was below the `0.001` gradient gate only for that
single seed-101 filtered history-500 arm (`0.0009006`; its full gradient L2
was `0.0038814`). The other seven final fresh norms ranged from `0.07265` to
`1.13128` and remained above the gate. This is a frozen local diagnostic of
the recorded Fe7C3 failed points. The history-500 run is an existing
optimizer parameter tested across materials, not a proposed default, and
these results do not establish a whole-SSW gain.
