# Flat-coordinate numerical kernels for VC integration

2026-09-10. `pamssw/standalone/generalized_numerics.py` separates existing numerical methods from Cartesian `Atoms`. It does not define VC coordinates, cell metrics, physical convergence or a new optimization policy.

`safe_lbfgs(q0,evaluate,*,gradient_norm,step_norm,gtol,max_step,maxiter,max_requests=None)` accepts flat q and `evaluate(q)->(E,dE/dq)`. Both norm callbacks take a flat vector and return a nonnegative finite scalar. The caller must explicitly define compatible atomic/cell scaling, gradient threshold and allowed step norm. Steps are rescaled by one scalar; this preserves their direction. Coordinate-dependent physical convergence requiring q must be handled by the caller or an appropriate evaluator-bound callback; no geometry is inferred here.

The implementation imports existing `_lbfgs_inverse_product`, `_accept_lbfgs_curvature` and Safe-total constants from `pamssw.relax`: memory10, empty-history scaling1/70, Armijo1e-4, backtracking1/2, at most20 line trials and minimum alpha2^-20. It uses complete E/g secants and the same positive-curvature gate. `max_step` is explicit because a 3N+6 vector cannot inherit an unexamined Cartesian 0.2 Å interpretation. No restart, inverse-Hessian absolute value, bias separation, adaptive scale or invalid-trial recovery was added. The caller is responsible for keeping the objective and coordinates continuous; this flat helper has no MIC image-signature reset.

`GeneralizedRelaxResult` stores last accepted q/E/g, status, accepted step count, attempted evaluator calls, accepted trace, secant and trial counters, and an optional error. Failed evaluations count as requests. Failed line search/evaluator leaves the last accepted state intact; first-evaluation failure has E/g=None. An exhausted request cap cannot trigger an extra evaluation. Trace contains initial and accepted states only; trial-count accounting is separate. Convergence at the last permitted step is recognized without another evaluator request.

`generalized_dimer(q0,anchor,*,rotation_bias,fd_step,max_hvp,tol,evaluate)` is the same plane-minimizing forward-secant algorithm as `paper_dimer_direction`: center gradient, biased Hn, negative tangent residual, symmetrized 2×2 eigensolve, and direct secant verification of each proposed direction. It returns existing `SoftModeResult` with a flat direction; `force_calls` denotes E/g calls. The Euclidean q metric, meaningful units and removal of forbidden/null directions remain caller responsibilities. Exceptions propagate; caller-side evaluation accounting must retain their cost.

Validation in `tests/standalone/test_generalized_numerics.py`: five tests passed, covering non-3N dimensions, trial failure rollback, budget and initial-error accounting, 20-trial failed Armijo rollback, real Cu13 EMT Safe-total accepted-trajectory/cost comparison with the existing Relaxer, and real Cu13 EMT direction/curvature/residual/cost comparison with existing Cartesian dimer. These establish algebra/API consistency. They do not establish that a proposed joint cell walker is mathematically or scientifically valid; VC chain rules and subsequent end-to-end tests remain separate.

## Accepted-coordinate-dependent stopping

`safe_lbfgs` now optionally accepts `convergence_norm(q,g)`. When supplied, it overrides the stopping/snapshot norm while retaining the same explicit gtol threshold. Every invocation receives copies of the **current accepted** q and gradient, including the final check after failed backtracking; trial states are never passed to this convergence callback. Default `gradient_norm(g)` behavior and existing Cartesian comparisons remain unchanged. The callback must avoid unaccounted E/F requests. It can use a mathematical inverse transform or exact accepted-coordinate keyed diagnostics recorded during existing evaluations.

A regression deliberately rejects a full step, accepts its half step, then rejects every subsequent trial. Callback records contain only the initial and accepted half-step pair, and final norm/state retain the accepted pair rather than the most recently evaluated rejected trial. Combined generalized/real-VC tests: **10 passed** after integration of the new callback.
