# GA-SSW behavior reconstruction (experimental)

This is an independent Python reconstruction of selected behaviors of the supplied
GA-SSW Java release. It is not a full GA-SSW implementation or a validated global
optimizer. Existing PAM-SSW runtime code is unchanged.

## Implemented scope

- Nonperiodic, three-shell NNA descriptor, including original count-only stable
  sorting and its atom-order dependence. Pair bond lengths come from the original
  jar; the prototype supplies no guessed element radii.
- Six-component descriptor similarity and projection onto frozen references.
- Projection-tolerance deduplication, lower-energy representative replacement,
  archive merge, energy window, and parent cumulative selection weights.
- Original Java probes compiled against supplied jars, never against decompiled
  source. Periodic real structures test similarity on original descriptors only;
  periodic coordinate-to-descriptor reconstruction is not implemented.

`merge_archive` requires an already deduplicated incoming batch: the original
collects unmatched new entries before appending them. `compete_cumulative` matches
the original only for finite energies, more than two parents, and positive energy
span. Degenerate inputs raise an error instead of reproducing legacy NaN output.
The hard-coded original constants are compatibility facts, not recommended physics.

## Run frozen tests

From the repository root:

```bash
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 \
  pytest -q -p no:cacheprovider tests/reproduction/test_ga_ssw_parity.py
```

## Regenerate original-JAR fixtures

The separately extracted reference directory must contain `GA-SSW_program/sgn.jar`,
`GA-SSW_examples_run/global_exploration/GA-SSW/input/nna1.jar`, the example
`input-templates`, and `tools/jdk-17.0.2/bin/{java,javac}`.

```bash
python research/ga_ssw/run_reference_probes.py \
  --reference-root /home/gengjianrui/bin/pam-ssw-research/ga-ssw-20260909 \
  --output /tmp/ga-ssw-fixtures
```

The script compiles four small probes in a temporary directory, calls original
classes with 30-second limits, and reproduces a CPU=2 batching timeout with a
3-second limit. It makes no energy calls and starts no search. Commands, input
and jar SHA256 values, coordinates and periodic cell lengths/angles are recorded.
Temporary class paths in provenance describe the completed run; rerun the script
to rebuild them. Java text sources are in `research/ga_ssw/java`.

`water-coninfo.base` was generated by original SGN `BaseConInfo` using its internal
unseeded RNG and then frozen. Regeneration deliberately reuses it. Independent
random regeneration is possible using `VirtualReferenceProbe`, but would create a
new experiment: the exact classification outcome is reference-dependent.

The real water, AlOH and molecular-crystal coordinates come from uploaded examples.
Core fixtures additionally contain explicitly artificial contract probes (IDs 8–9)
to isolate representative replacement and the nontransitivity of tolerance matching.
They are not physical configurations or scientific performance evidence.

## Evidence limits

Seven tests establish selected behavioral agreement and reproduce one concrete
failure of atom-order invariance. They do not validate GA-SSW efficiency, full
archive behavior over a trajectory, periodic descriptors, crossover/mutation,
KMeans beyond the stored k=1 oracle, native SSW/LS kernels, or variable-cell search.
See `docs/research/2026-09-09-ga-ssw-behavior-parity.md` for findings and next steps.
