# 内层容差配对结果与决定

## 决定

保留现有bias_fmax=0.1，不推广0.2、不继续扫阈值。内层优化精度会改变整条偏置路径和退出时间，不能把更松的局部停止直接等同更低的总成本或相同探索质量。这是首外步开发实验，不是长期效率排名。

|输入/种子|搜索请求 0.1 → 0.2|实际Gaussian段数|0.2落点相对0.1能差/eV|结构解释|
|---|---:|---:|---:|---|
|C4H6/61|808 → 593|25 → 25|−0.000779|两落点图相同，对齐RMS0.0148Å，扭转约28.9°/27.8°；本配对有保留近似构象变化且省调用的信号|
|C4H6/67|763 → 479|25 → 25|−0.083934|0.2落点接近起点：RMS0.0115Å、扭转178.7°；0.1落点扭转331.7°，不是等效发现的加速|
|C60/17093|708 → 1118|4 → 12|−5.830856|两个落点图不同；0.2多花410请求并降到更低能，不能简单排名|
|C60/17094|2186 → 1516|12 → 8|+2.009897|两个落点图不同；0.2省670请求但落点较高能，不能简单排名|

C60图结论在1.8/1.64Å均一致，全部端点连通；同图不等于同盆地，未做Hessian或成笼验收。C4H6两个种子共享同一初始结构，不是两个独立体系。
