# C4H6 archived landing topology audit

**Question.** Do the previously observed connected, force-qualified C4H6 landing events represent repeated visits to the same element-labeled bond graphs, or discovery of additional graph topologies? Competing explanations are (1) LS mainly increases repetitions of a few topologies and (2) LS exposes more distinct topologies. This distinguishes event counts from topology coverage; it does not test why a topology was reached.

**Scope and fixed comparison.** Offline audit only, using the four existing MH-1/omol records `ssw-seed61`, `ssw-seed67`, `native_ls-seed61`, and `native_ls-seed67` under `c4h6-mh1-coverage-20260924`. No new PES calls, trajectories, thresholds, rewards, or C60 inputs. The sole comparison is the existing LS toggle within each seed; arms are not pooled across seeds for class identity.

**Qualification and identity.** Process every archived landing, irrespective of any earlier graph-change flag. A candidate must have `converged=true`, `surface="true"`, saved `max_force <= 0.03 eV/A`, and one connected component. Construct a nonperiodic distance graph with the archived C4H6 cutoffs H-H 0.8400000095367432 A, H-C 1.190000033378601 A, and C-C 1.6399999618530273 A. Nodes carry atomic number; exact NetworkX graph isomorphism removes dependence on atom ordering. Report all qualified connected candidates and the accepted subset separately. For each stream, count noninitial graph classes and report the record and cumulative archived E/F request count at first discovery; cumulative cost starts with the initial evaluation requests.

**Run and output.** From the checkout root, run `python research/ga_ssw/evidence/ls-climb-depth-panel-20260926/audit_topology.py` (JSON to stdout), or provide `--output <new-path>`; existing output paths are refused. The script reads the archived `result.json` files and reports source SHA256 values. Do not overwrite prior audit products.

**Interpretation and stop.** A higher event count with unchanged distinct-class count supports repeated graph visits as the source of the earlier event signal; more noninitial classes supports broader graph-topology coverage in these runs. Same graph does not imply the same geometry or minimum; different graphs are not certified chemical products. These data do not establish reaction paths, barriers, or a causal LS mechanism. Stop after this zero-PES audit; if the required stored fields or source files are missing, report the gap without substituting new calculations.
