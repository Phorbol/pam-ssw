# Historical C4H6 pool identity re-archive (zero PES, prepared)

**Candidate denominator and order.** Each run's complete raw `minima` count and 400 record count are verified against its exact input JSON SHA. Input order is the initial geometry followed by every record landing with `converged=true`, `surface="true"`, and finite saved `max_force <= 0.03 eV/Å`, in raw record order. This is the existing numerical landing qualification, with no connectivity or graph filter. Both accepted and MC-rejected qualified landings enter the archive. Missing/unqualified landing attempts remain explicitly counted and listed, not replaced by `last_atoms`. Current records are expected to yield `initial + qualified landings == raw minima count`; otherwise that run aborts rather than silently changing the denominator.

**Frozen comparison.** Rebuild two independent empty archives per arm and call existing `add(state, energy, parent_id=None)` over identical observations: ordered `MinimaArchive` versus the committed `ASEPermutationArchive`, both `energy_tol=0.001 eV`, `rmsd_tol=0.1 Å`. No new reward, online adapter, PES call, graph-based candidate filtering, threshold change, or archive cross-seeding. Save both complete observation-to-entry maps and per-observation matcher comparisons/CPU time plus add time. Where the two mappings differ, report the source record for the candidate and both chosen representatives, their signed/absolute energy differences, RMSDs under each matcher, and frozen graph class labels when available. Also report archive `energy_mismatch_hits` and maximum energy mismatch.

**Graph labels and interpretation.** Topology class IDs come only from the pre-existing per-run audit: initial representative plus its frozen `all_candidate_noninitial_first_discoveries`, compared by the existing exact element-labeled graph-isomorphism procedure and cutoffs. These labels are annotations only; they do not select archive inputs. Unmatched graphs are marked `not_in_recorded_topology_classes`. A mapping difference is an approximate matcher-defined identity difference at the stated thresholds; even when two candidates map to the same element-labeled graph class, that does not prove a shared geometric minimum. Energy differences or class differences flag cases for review; neither alone is proof of a matcher error or basin truth. This offline replay cannot infer historical online restarts or search performance.

**Cost and stop conditions.** No PES is evaluated. For each archive record exact `_rmsd` invocation count/time during `add`, total `add` time, pre-existing source EF request total, and processed/total candidates. Each Slurm array task has one CPU and a five-minute wall limit; the script stops and writes its partial denominator at 230 seconds if needed. At most four arm tasks run concurrently. Each result path is unique and refuses overwrite. Input or matcher source mismatch, raw minima denominator mismatch, or noncontiguous record indices aborts that arm.
