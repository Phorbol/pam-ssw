# MinimaArchive identity probe on archived C4H6

**Question and hypotheses.** Does the existing `MinimaArchive` treat exact copies and rigidly transformed copies as duplicates, while treating an exactly identical geometry under a legal same-element atom permutation as new? A second possible concern is whether the existing RDF-style descriptor is invariant to these transformations. This probe checks the recorded matcher/descriptor behavior only; it does not assume a shared bond graph means a shared minimum.

**Inputs and sole factors.** Use the committed C4H6 `topology-audit.json`, every archived initial geometry, and each arm/seed's first representative of a noninitial element-labeled topology class. Within each geometry, test (i) exact copy, (ii) proper rigid rotation plus translation using NumPy seeds 1, 2, 3, and (iii) positions permuted only among equal atomic numbers using the same seeds. Same-element permutation preserves the exact physical point set and composition. No PES, optimizer, energy change, graph cutoff change, or matcher parameter sweep.

**Readout.** Instantiate the existing archive with `energy_tol=0.001 eV` and `rmsd_tol=0.1 Å`, matching the approved PAM pool protocol. For each query, record `find_match`, archive entry count before/after insertion, RDF histogram and full structural-descriptor L2 differences. The descriptor is the existing untyped pair-distance RDF histogram plus distance/contact statistics. Record source hashes, transformation matrices/permutations, and `MinimaArchive` code provenance in the output.

**Execution.** Run `probe.sbatch` from the `c60-local-defect-qualification` checkout. It requests CPU-MISC, account `sjtu-caoxiaoming`, QOS `rush-cpu`, one task, and a 5-minute wall limit; PES evaluations are zero. Output is written only to this evidence directory.

**Interpretation/stop.** If legal permutations miss despite identical coordinates as an unlabeled set, the matcher has the documented atom-order limitation. If descriptor differences remain zero while matcher misses, those reordered points may be treated as maximally familiar by novelty/density terms but still admitted as separate entries. This can affect PAM novelty bookkeeping for duplicate representations; it does not show a general search bias or mean distinct graph topologies are duplicate minima. Report all outcomes and stop; no API/core/default changes follow from this probe.
