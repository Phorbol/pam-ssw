# MinimaArchive C4H6 identity probe

**Result.** On 30 archived geometries (the four run initials plus 26 first representatives of noninitial topology classes), all 30 exact copies and all 90 proper rigid rotation/translation queries matched the reference entry. All 90 same-element atom permutations failed `find_match` and increased the one-reference archive from one to two entries, despite preserving the exact geometry as an unlabeled coordinate set. The RDF histogram was bitwise identical for every rigid transform and permutation (maximum histogram L2 difference 0). Full descriptor differences for transformed structures were at floating-point roundoff scale; bitwise equality was not a valid invariant for those floating summary terms.

**Implication for the existing PAM accounting.** This is the documented ordered-atom matcher limitation in `MinimaArchive`, demonstrated on the real C4H6 structures. It can affect new-minimum/novelty credit if identical geometries enter in different atom orders. In a one-prototype archive with identical energy, the permuted candidate's identical descriptor gives density 1 and coverage gain/novelty 0.5, while `find_match` reports it new: `ProposalScorer.score = 0 + 1 + 0 + 0.5 - 0 = 1.5`. The exact or rigidly transformed duplicate is instead classed duplicate and scores `0 + 0 + 0 + 0.5 - 1 = -0.5`. The adapter uses positive score to credit node success, so representation-only duplicates can receive false new-minimum success credit and create extra entries. The existing all-pair RDF descriptor itself does not distinguish atomic species or atom labels; repeated descriptors can also raise density/descriptor degeneracy and change effective archive weights. These are risks shown by the matcher and scorer semantics, not evidence that archived C4H6 trajectories actually contained reordered duplicates.

The C4H6 trajectories keep a consistent atom order, so this probe does not establish contamination in the four archived runs. A shared graph class still does not imply a shared minimum. No repair or parameter change follows from this diagnostic.
