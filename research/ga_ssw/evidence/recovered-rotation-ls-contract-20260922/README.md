# 恢复 CBD 与 NativeLS：组合接口检查

类别：实现检查；不是搜索性能或材料物理验证。

使用既有 Cu13/EMT 与显式诊断 LS 参数，调用 `run_ssw(ls=..., recovered_rotation=...)`。核心源码及公共 API 未改。

CPU 1441437 的实际命令见 `run_tests.sbatch`；`pytest-1441437.txt` 为 **2 passed in 0.58s**。测试源码为 `tests/standalone/test_recovered_rotation_ls.py`。第一项核对软面预淬火、恢复旋转记录、去偏置落点的独立 EMT 能量/力、响应单位和请求成本闭合。第二项核对连续两外步与断点续跑的成本、LS 状态表和当前坐标；续跑按现有契约显式传入 LS 设置。

非零 rotation bias 不是 LS 力参与旋转的独立证明；本检查不宣称这一点，也不宣称全局优化或通用默认优势。Cu 参数为原测试夹具值，不是材料推荐参数。
