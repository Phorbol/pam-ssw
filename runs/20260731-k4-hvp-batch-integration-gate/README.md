# K=4 中心差分受力批处理集成门

本实验只检验一个工程实现是否保持同一个物理算法：

- 每次方向选择生成四个候选原子位移方向；
- 对每个方向在当前结构两侧分别移动 `1e-3 Å`；
- 用两侧真实势能面的力差估计 Hessian 沿该方向的作用；
- 逐结构调用与八结构图批处理必须选择同一个方向；
- 两种实现都必须记为八次真实力评估，不能把一个 GPU batch 记为一次；
- 批处理只在 C60 和固定底层 PdO 两个体系都达到中位数 `1.3x`
  时间加速时通过。

测试包含初始步和已有上一轮位移（动量候选）两种物理上下文。MACE
模型、输入结构、固定原子定义、候选方向随机种子和有限差分步长全部冻结。
本门不改变 SSW 的上坡方式、偏置势、局部软化、淬火、极小值选择或生产默认值。
