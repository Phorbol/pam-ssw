# G-UP0: explicit displacement versus biased-PES relaxation

## Physical question

After SSW has already selected a direction and execution scale, does relaxing
the explicitly displaced structure on the accumulated biased PES change the
true-PES basin reached?  The paired states are

\[
x_k^{\mathrm{explicit}} = x_k + \sigma_k u_k
\]

and the recorded production checkpoint

\[
x_k^{\mathrm{relaxed}} =
\operatorname{Relax}_{E+V_{\mathrm{bias}}}
(x_k + \sigma_k u_k).
\]

Both are quenched by the same true-PES protocol.  This gate changes no
starter, direction source, direction selection, HVP, step scale, Gaussian
bias, true quench, matcher, selector, or production default.

## Frozen cohort

- system: C60 only;
- starters: `intermediate_accepted`, `plateau_accepted`;
- seeds: 42, 43, 44;
- action families: `D0_exact_anchor`, `K4_discrete`;
- recorded horizons: 1, 2, 4 when a proposal-relax trajectory exists;
- expected pairs: 34;
- additional budget: at most 5,000 force evaluations;
- direction-oracle and biased-proposal-relax evaluations in replay: zero.

The first frame of every proposal-relax trajectory is the exact
`ProposalRelaxationTask.initial_state`: every Relaxer backend invokes its
trajectory callback before taking an optimizer step.  Source evidence and
each source trajectory are verified by SHA256.

## Stopping rules

- Retain biased relaxation as causally active when a complete frozen
  `(starter, action, horizon)` context has `RELAXED_ONLY_ESCAPE` in at least
  two of three seeds.
- Call exact redundancy only when every pair is learnable and every pair
  either returns to the starter in both arms or reaches the same escaped
  minimum in both arms.
- Any other mixture changes no production default.

This is a local counterfactual branching from the original relaxed path.  It
cannot promote an online explicit-only walk because later branch states were
not generated by preceding explicit-only steps.
